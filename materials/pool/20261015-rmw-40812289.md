# 进商场不仅图买，还要能“待”

来源：http://finance.people.com.cn/n1/2026/1011/c1004-40812289.html
发布：2026-10-11
文号：（无）
抓取：2026-10-15
时效：半年（自 2026-10-11 起）
主题：城市更新、民生保障
采用：材料呈现商场从购物转向体验业态的转型及其同质化难题，有具体做法、案例和数据，且存在尚未解决的问题，可入库。

## 背景
- 过去40多年里，商场的形态经历了好几轮变化。
- 上世纪八九十年代，百货商场是体面的消费场所，人们围在柜台前，为添置一台电视、一块手表郑重挑选。
- 后来，购物中心模式兴起，餐厅、影院、电玩城搬进商场，逛商场除了买东西，还能顺便吃顿饭、看场电影。
- 电商普及之后，商场发现，光靠卖货很难吸引顾客常来光顾。
- 当线上购物能把绝大多数商品送到家门口，消费者愿意走进商场，图的已不是“买东西”，而是“值得待”。

## 做法（已经发生的）
1. 国务院办公厅印发《加快培育服务消费新增长点工作方案》，提出依托消费新业态新模式新场景试点等平台载体，支持建设若干消费带动作用强的情绪式、体验式服务消费新场景。
2. 商场引入体验业态、举办趣味活动，用供给端的场景创新去对接需求端的体验升级。
3. 攀岩馆占据了显眼位置，养生馆开进了快时尚扎堆的楼层，中庭搭起台子办起了各种趣味比赛。
4. 商场举办嗑瓜子比赛、“偷吃”大赛、摘豆角挑战等趣味活动。
5. 成都锦江区青年磁场购物中心以艺术展览为转型切入口，把体验区与商业区的比重划为6∶4。
6. 厦门星河COCO Park引入滑板、击剑等多种运动项目，并联合场内品牌举办社群赛事。

## 成效
- 今年上半年，我国服务零售额同比增长5.3%。
- 厦门星河COCO Park客流和销售额都有明显增长。

## 争议 / 难点
- 眼下不少商场给出的答案越来越相似，你家有攀岩，我家也引进；你办趣味比赛，我也办。
- 消费者逛来逛去觉得似曾相识，新鲜感一过，就不会再特意到访。
- 办活动热闹一两天，活动一撤，客流也跟着散了。
- 这对商场的运营能力提出了更高要求。

## 建议 / 主张（还没发生的）
1. 一个健康的商场生态，应该是体验、餐饮、购物等多种业态形成良性互动，而不是简单地用一个替代另一个。
2. 商场真正要经营的，是把不同消费需求串联起来，持续提供好内容、好体验、好服务的供给能力。
3. 真正让消费者从“来一次”变成“常来常往”的，靠的是一整套消费生态的支撑。
4. 真正有效的场景创新，要立足自身区位条件和客群特点去做差异化定位。
5. 活动是引子，生态才是底子。
