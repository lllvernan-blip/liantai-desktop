# 不搞竞争性货币贬值，中国有底气

发布：2026-10-11

抓取：2026-10-15

主题：（未标）
采用：材料有明确政策立场、可核数据以及已发生的汇率制度安排，能支撑概括、分析与对策类题，故入库。

## 背景
- 国际社会存在关于人民币汇率的不实论调。
- 国际社会将人民币汇率问题政治化、工具化。
- 当前全球经济增长动能疲弱，单边主义和保护主义抬头。

## 做法（已经发生的）
1. 中国人民银行近日发布关于人民币汇率的政策立场，明确“中国没有必要，也无意通过汇率贬值获取贸易竞争优势，从不搞竞争性货币贬值”。
2. 中国实施以市场供求为基础、参考一篮子货币进行调节、有管理的浮动汇率制度。
3. 中国始终坚持让市场在汇率形成中发挥决定性作用。
4. 2017年后，中国人民银行不再预设汇率目标水平，不干预汇率长期走势。
5. 面对疫情冲击、关税战等重大外部挑战时，中国人民银行进行“有管理”，以防范汇率短期大幅波动、校正市场非理性预期，避免汇率出现短期破坏性超调影响金融稳定。

## 成效
- 2005年汇率改革以来，人民币对美元汇率累计升值23%。
- 国际清算银行测算的人民币名义有效汇率升值超50%。
- 国际清算银行测算的人民币实际有效汇率升值35%。
- 2005年汇率改革以来，中国出口在全球的份额总体保持上升态势。
- 过去5年，中国高技术产品进出口年均增长7.9%。
- 2025年，中国高技术产品进出口同比增速达11.4%。
- 2025年，中国高技术产品进出口对整体外贸增长的贡献率接近六成。
- 约30%的贸易采用人民币结算。
- 企业外汇套保比例达到30%左右。
- 贸易对汇率波动的敏感度显著下降。
- 人民币汇率的弹性不断增强，双向浮动特征更加明显。
- 人民币汇率能够发挥宏观经济自动稳定器的作用，并为货币政策自主性提供支撑。

## 争议 / 难点
- 中央银行基本不具备影响汇率中长期走势的干预实力。

## 建议 / 主张（还没发生的）
1. “十五五”期间，中国将继续坚持汇率市场化改革方向。
2. “十五五”期间，中国将保持人民币汇率在合理均衡水平上的基本稳定。
3. 中国将以自身高质量发展为全球经济复苏注入持久动力。
4. 推动全球贸易平衡需要逆差国和顺差国共同行动。
