# 人民直击｜“全国都有的补贴，为啥这里没法用？”

来源：https://society.people.com.cn/n1/2026/0921/c428181-40802415.html
发布：2026-09-21
文号：（无）
抓取：2026-10-15
时效：半年（自 2026-09-21 起）
主题：民生保障、基层治理
采用：面向全国的失能老人补贴在农高区落不了地，平级协商、资金无法直达等原因具体到部门与日期，问题至今未解决。

## 背景
- 李萍（化名）父亲全身瘫痪，在黑龙江佳木斯国家农业高新技术产业示范区（以下简称“农高区”）一家养老院住了多年；父亲每月照护费约3000元，退休金无法覆盖
- 今年初，李萍看到新闻说中度以上失能老年人可以领取国家补贴，去办手续时被告知用不了；几个部门都说农高区行政区划特殊，补贴发不下来
- 按照规定，补贴通过养老机构核销；6月下旬，记者走访了佳木斯农高区5家养老机构，多名负责人证实，他们的确用不了，因为补贴由哪里发放还没有确定
- 佳木斯农高区属于开发区，开发区的功能定位是产业发展
- 2017年，《国务院办公厅关于促进开发区改革和创新发展的若干意见》提出，完善开发区管理体制，其中包括充分依托所在地各级人民政府开展社会管理、公共服务和市场监管，减少向开发区派驻的部门，逐步理顺开发区与代管乡镇、街道的关系

## 做法（已经发生的）
1. 政策实施前，佳木斯市民政局要求农高区和富锦市的民政部门协调财政部门打通数据
2. 6月下旬，佳木斯市民政局下发督办函
3. 近几年，多地出台政策，要求开发区聚焦经济发展主业，有序剥离社会事务管理职能
4. 2024年，福建省出台开发区管理办法，提出具备条件的开发区逐步剥离社会事务管理职能，交由属地政府承担

## 争议 / 难点
- “农高区管委会是佳木斯市政府派出机构，没有行政区划，补贴资金无法直达。”佳木斯农高区管委会社会事务管理局工作人员表示
- 农高区位于佳木斯市下辖县级市富锦境内，农高区和富锦市两家平级，需上级部门组织协商
- 农高区管委会社会事务管理局相关负责人表示，两地签订协议即可打通数据；但直到9月14日，数据仍未打通
- 基于事权特殊性，一些开发区处理社会事务时，需上级政府授权，与同级政府协商，往往出现协调不畅
- 张峰（化名）在福建一开发区负责综合监管工作，今年上半年，他所在部门被安排一项安全生产管理任务，但部门并未获得这项授权；他们说明后，工作没有派给他们
- 张峰表示，在开发区的企业面临上级政府、属地、开发区和街道多头检查；以申报奖项为例，属地要求开发区开证明，但开发区无权限，企业只能再回到属地，不仅增加了行政管理成本，也增加了企业负担
- 张峰表示，他对开发区剥离社会事务管理职能的感受并不明显，仍有不少无权限和重复的工作让他感到疲惫
- 高恩新（华东师范大学公共管理学院教授）表示，他调研过很多开发区，社会事务运行不畅的核心问题是开发区和属地政府的财权分配机制；一些属地政府认为，“好处”被开发区拿走了，属地凭什么承担大量社会事务
- 高恩新表示，企业集中在开发区，开发区获得了招商引资、税收返还的收益，而属地没有这一优势，动力和财力均不足以支撑其承担开发区的社会事务
- 2025年11月，内蒙古鄂尔多斯市审计局在专项审计调查中发现，经济开发区普遍存在长期承担属地政府社会职能的历史问题，及精简剥离社会职能工作推进缓慢、园区管理服务效能不足的情况

## 建议 / 主张（还没发生的）
1. 黄建洪（苏州大学政治与公共管理学院教授）表示，市政府应对农高区管委会社会事务负责，可以通过市级直管、委托代管等方式落实补贴
2. 黄建洪表示，中央转移支付在地方落地遇阻，往往在于部门间主动衔接意识不足，真正有效的责任落实是要把民生事项具象化为绩效考核指标
3. 高恩新表示，推动开发区高质量发展，要让其轻装上阵，聚焦主责主业，社会事务回到属地政府
4. 高恩新表示，要保障属地政府有效支撑社会管理、公共服务等事务，需制定利益共享财权分配机制，平衡财权与事权
5. 黄建洪指出，理顺开发区和属地关系，需健全从权责清单、协调机制到绩效考评、巡察整改的全流程体制
6. 黄建洪提出，权责清单要通过地方性法规明确，协调机制要常态化、规范化，绩效考评要将久拖不决的民生问题纳入，巡察整改要重点关注反复出现的问题
