# 一碗线面，家乡味多了新故事（神州看点·一方水土一方味）

主题：乡村振兴、文化传承
采用：材料虽以成效为主，但保留了一个尚未解决的问题——古法线面制作让年轻人望而却步、最年轻手艺人已52岁，且文中记录了注册商标、建培训基地、合作社与高校合作研发等已发生的具体做法，有可核数字，能同时支撑概括题与对策题。

## 背景
- 福建莆田市秀屿区埭头镇汀港村三面环山、一面临海，传承着纯手工制面的古法技艺，每逢春节、中秋，古法线面总是供不应求。

## 做法（已经发生的）
1. 汀港村统一注册了商标，设计了精致包装，改变过去农户散装零卖的模式。
2. 汀港村规划新建6层标准化线面制作培训基地，首层主体结构施工已经启动。
3. 汀港村借力新媒体和物流网络，古法线面一路卖到全国多地。
4. 福州市闽侯县荆溪镇埔前村的闽食福农业专业合作社建成1000多平方米的室内线面加工标准厂房，恒温恒湿，可以实现全天候生产加工。
5. 闽食福农业专业合作社与高校合作开展产品研发，针对不同场景推出方便线面、儿童线面等多类线面产品。
6. 中华老字号聚春园的闽菜大师梳理传统烹制技艺，研发海鲜线面、红糟鸡汤线面、鲍鱼线面等多款新品。
7. 福州发掘线面的“福寿”文化内涵，走“文化+旅游+产业”的路子，把线面做成一张“文化请柬”。

## 成效
- 2025年，闽食福农业专业合作社的线面产量超500万公斤，产值超1亿元。
- 一条非遗研学线路正在形成。

## 争议 / 难点
- 古法线面制作曾让不少年轻人望而却步。
- 汀港村里最年轻的制面手艺人林秀梅，如今也已52岁。
- 69岁的林文豹已在面架前守了45年。
- 古法线面制作对气温湿度要求极高，大多集中在农历九月至十二月，离了最佳时节，口感便难臻完美。

## 建议 / 主张（还没发生的）
1. 汀港村党支部书记林炳贤说，老手艺是宝贝，得想办法让大家在家里就能赚到钱。
2. 走进汀港村码头自然村，未来这里将集非遗展览、研学课堂与体验空间于一体，预计每年为村集体增收20万元。
