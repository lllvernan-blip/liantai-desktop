# 人民直击｜多头监管，苏州非法码头4年关不掉

来源：https://society.people.com.cn/n1/2026/0907/c428181-40793502.html
发布：2026-09-07
文号：（无）
抓取：2026-10-15
时效：半年（自 2026-09-07 起）
主题：生态环保、基层治理、法治建设
采用：非法码头被查处85起仍关不掉，部门职责分割、区市互相推诿、罚款与营业额悬殊，矛盾集中且数字可核。

## 背景
- 一家名为攀峰再生资源回收有限公司的企业，长期在江苏苏州市姑苏区储运路7号私设码头，偷运未经处理的建筑垃圾和再生石料；苏州市交通运输局曾多次现场执法，都无法拔除这座非法码头
- 苏州市交通运输局明确表示，攀峰公司从未取得经营范围为装卸作业的港口经营许可证，从未通过岸线审批，未开展过港口基本建设交竣工手续，也未取得过港口、航道、海事部门关于码头装卸的其他批准或许可，码头属于“非法装卸点”
- 攀峰公司方面称，2018年至2022年，公司一直借用苏州市物资储运有限责任公司的港口经营许可证，经营范围曾纳入港口经营许可管理，2022年4月港口经营许可证到期后，相关资质才被取消
- 苏州市交通运输局港政执法大队副大队长樊宇杰说，“港口经营资质是不能租借的”，攀峰公司自始至终都没有港口经营资质
- 攀峰公司有关负责人说，为了取得码头合法身份，曾多次向苏州市交通运输局申请水上货物装卸的港口经营许可证，但被拒绝；苏州市交通运输局称，攀峰公司申请“水上货物装卸的港口经营许可”的两项必备材料均缺失：一是无港口岸线使用批准文件，二是无码头设施竣工验收合格证明，不满足许可申报条件
- 2021年，江苏省政府印发《大运河江苏段核心监控区国土空间管控暂行办法》，大运河江苏段主河道两岸各2千米的范围被定为“核心监控区”，攀峰公司正位于核心监控区内
- 该暂行办法第十一条明确规定，加强岸线管理，严格保护和合理利用岸线，维护岸线基本稳定
- 苏州市交通运输局综合行政执法支队（苏州市地方海事局）在8月7日的回复中明确表示，攀峰公司所处地块产权归属物资控股集团，产权方原来将地块租赁给胜达物流公司，租赁合同明确地块仅可作仓储使用，不含港口码头相关经营权限；后胜达物流公司擅自转租给攀峰公司，私自扩大租赁范围、变更租赁用途
- 8月5日、6日、7日、20日、27日，记者在苏州古运河白洋湾附近5次蹲守，都看到从深夜至次日凌晨，多艘货轮在京杭大运河苏州段这段河岸装载建筑砂石、渣土后驶离
- 攀峰公司有关负责人受访时表示，公司各类资质、环评手续齐全，所有建筑垃圾都经过了分拣和处置
- 渣土车司机王军（化名）告诉记者，他给攀峰公司运送建筑垃圾已有一段时间，建筑垃圾进厂时会做简单区分：“混掺大量生活垃圾的会进入流水线分拣”，“比较‘干净的’直接进入码头旁的堆场卸货，然后装运上船”
- 根据江苏省住房城乡建设厅等部门编制的《建筑垃圾资源化利用产品应用及质量控制指南》，“骨料类”为“建筑垃圾经分选、破碎和筛分等工艺处理后得到的骨料”
- “翔运69”号船主提供了一份由江苏省建筑工程质量检测中心有限公司出具的检测报告单，称所运货物为“路用再生骨料”；该检测报告单的检测时间是“4月16日—4月17日”，而攀峰公司出具的产品合格证显示，货物生产日期、检验日期均为“8月7日”，二者相差近4个月
- 攀峰公司有关负责人称，检测报告拿错了，是管理上的小漏洞
- 湖州市交通运输局港航与海事执法科科长武月朝介绍，“溧航机1662”上的货物来自苏州攀峰公司，产品合格证上说的是“建筑骨料”，生产日期是8月15日，但检测报告日期是8月3日
- 一名从事建筑垃圾加工的企业负责人告诉记者，有些建筑垃圾会包含一些装修材料，比如油漆等污染废料，若不处置，偷运到水塘或地下填埋，将会造成严重污染

## 做法（已经发生的）
1. 多年来，苏州市交通运输局港政执法大队曾数十次现场执法，明确告知攀峰公司其行为属于“在岸线上非法从事港口经营活动”
2. 2024年8月，港政大队曾在距离攀峰公司岸线3米的水域处设置警示标识（打铁柱子），一是警告船舶此处不是合法泊位，二是警示标识能让船舶无法靠岸
3. 8月16日下午，靖江市城管局和海事处执法人员登上“翔运69”号船检查
4. 8月18日，一艘编号“溧航机1662”的船舶在浙江湖州市南浔区一处滩涂违法倾倒时被当地查获，湖州市交通运输局已对该船舶立案审查

## 争议 / 难点
- 岸上与水上执法职责分割：苏州市交通运输局综合行政执法支队（苏州市地方海事局）表示，他们无职权处理岸上非法行为，相关取缔工作应由属地人民政府负责；姑苏区城管委相关负责人表示，城管部门主要监管建筑垃圾运输到进厂环节，也就是从建筑工地到攀峰公司大门口这段距离内是否合规，攀峰公司厂区内对建筑垃圾如何处理，不属于城管委管辖
- 记者追问攀峰公司装船运输的到底是建筑垃圾还是骨料、骨料是否合格，姑苏区城管委有关负责人表示，这属于企业生产的产品，应当由市场监管部门来监管；记者就此咨询江苏省相关部门的工作人员，对方表示，城管委应当对建筑垃圾的转运加工进行全流程监管
- 当地多名政府工作人员表示，苏州市有关部门曾召开会议，明确姑苏区政府牵头处理此事；姑苏区政府副区长王晋向记者表示，姑苏区没有交通管理职能，苏州市也没有下放过相应权力，因此非法码头一事应由苏州市交通局执法与监管
- 2024年8月港政大队设置警示标识时，遭遇攀峰公司部分员工暴力阻挠；樊宇杰说，“有人跳到我们的工程船上，抢了操作机械，将铁柱子（警示标识）拔掉了。还有人在岸上通过长臂挖掘机，把柱子拔掉了。”
- 攀峰公司有关负责人承认阻挠一事，但表示“交通部门没有通知我们（要设立警示标识），而这个码头岸线本来就是我们的。官方说我非法，我们一直不服气。”同时，该负责人承认码头没有取得合法手续
- 记者蹲守期间，曾有一艘海事巡逻艇赶到现场，执法人员手持扩音器对货轮喊话：“此处禁止停靠，请尽快驶离！”但现场照常作业，1个多小时后，满载的货轮一路向北，消失在夜色中
- 由于攀峰公司使用的是“非法装卸点”，前来接运的货轮无法按正常程序报港；“翔运69”号船的进出港报告单上，停靠泊位为“苏州市富利峰建材有限公司1号泊位”，即攀峰公司隔壁一家公司的码头
- 港政大队提供的一份《攀峰水域船舶处罚情况统计表》显示，2022年12月至今，攀峰公司被查处的85起违规事件，有最终靠岸记录的有67起，其中省内47起，跨省20起，有18起不知所终；表内没有登记船只运输的是什么
- 《中华人民共和国生态环境法典》中，关于未经批准转移固体废物出省、自治区、直辖市行政区域贮存、处置，以及转移固体废物出省、自治区、直辖市行政区域利用未报送信息的行为，有明确法律责任规定
- 交通运输局有关工作人员表示：“是不是建筑垃圾，需要城管和环保部门认定，交通部门无法认定。”
- 2022年至今，苏州市交通运输局查处的攀峰公司沿岸水域船舶违法行为累计罚款30余万元，而攀峰公司去年的营业额高达1.1亿元；交通运输局一名执法人员无奈地表示，“平均一起处罚不到5000元，我们最多一起罚款七八千元”，按规定就只能罚款这么多
- 以苏州发货靖江为例，一名船主表示，千吨级货船的水运费用约为8元/吨；网络货运平台公开询价信息显示，从苏州整车发运建筑骨料至靖江市约45元/吨，水运、陆运二者运费相差数倍
- 一名干部向记者坦言，“为什么会允许这样一座非法码头存在？实际上是城市发展和居民生活有处理建筑垃圾的需要。但是不是非得这家企业来做，就不一定了。”
- 今年3月，中央第九生态环境保护督察组向江苏、浙江、安徽反馈大运河生态环境保护专项督察情况，指出“大运河生态空间管控不到位”“有的港口码头取缔拆除不到位，仍违法装卸”
- 攀峰公司有关负责人透露，公司目前是苏州最大的建筑垃圾处理工厂，去年处理建筑垃圾100多万吨，税都交了1200万元，日均处置建筑垃圾约600辆车；多位业内人士分析，以每车收取处置费600元估算，攀峰公司日均收入约36万元
