# 人民直击｜隐蔽购物换了“新马甲”，拉萨…

来源：http://society.people.com.cn/n1/2026/1008/c428181-40810439.html
发布：2026-10-08
文号：（无）
抓取：2026-10-15
时效：半年（自 2026-10-08 起）
主题：基层治理、法治建设、作风建设、民生保障
采用：材料揭露旅游市场强迫购物隐形变异乱象，有矛盾、有数据、有已发生的多部门突击检查与监管机制建设，且问题尚未解决，可出概括、对策等题。

## 背景
- 今年5月，有游客家属通过人民网“领导留言板”投诉，其亲属在拉萨跟团时被导游带往一处养生场所，工作人员借问诊名义夸大病情，最终花费21040元购买了8个月疗程的“藏药”。
- 随着旅游市场回暖，强迫购物等乱象在高压整治下改头换面，部分违规购物场所披上“非遗体验馆”“藏医诊疗点”等外衣。
- 记者以游客身份联系了一家报价较低的拉萨一日游旅行社，发现报名环节地接人员首先询问记者是否为本地常住人员，确认为外地游客后方允许登记。
- 记者发现后续门票预约均在私域渠道完成，全程规避公开交易。
- 游客须凭团队参观证方可进入购物点。
- 次日行程首站并非景区，而是藏游坛城二楼一处隐蔽的“藏医问诊点”。
- 该“藏医问诊点”入口隐秘，游客进门需佩戴胸牌，禁止拍照。
- 现场4至5名身着深色夹克的人员，在未公示行医资质的情况下，通过几分钟“看手诊”便指出游客存在各类“健康隐患”，进而推荐每疗程上千元的藏药，其标价明显高于市场水平。
- 随后的“藏家生活体验”环节，工作人员在简要介绍藏文化后，开始推销标价2000—3000元的银梳子，称“煮水喝有益身体健康之功效”。
- 当记者试图询问详情，导游即以“赶行程”为由催促离开。
- 当日承诺的正餐变为一袋小面包和一盒牛奶。
- 下午的布达拉宫行程，导游则以预防高反为由建议游客自由活动。
- 在另一处被举报点位，早晨7点半，尚不到正式上班时间，一名黑衣男子便已守在前门望风，面对试图进入的记者，以“内部未营业”为由劝离。
- 上午9时许，一辆载满游客的大巴悄然从后门驶入，待车辆停稳，该男子随即准备锁上前门，腰间的对讲机里传来确认车辆到位的指令。
- 记者调查发现，此类场所线上通过直播、私域流量发布低价套餐引流。
- 记者调查发现，此类场所线下采取“专人望风、对讲机调度、非上班时间接团”的“游击”策略。
- 业内人士算了一笔账：进藏大交通、地接、用车、食宿均有刚性支出，市面上两三千元包吃住的低价团，很难通过正常服务盈利。
- 另一名旅行社负责人指出，此类低价团往往依赖购物回扣平衡成本。
- 合规经营的“正价团”因成本较高，报价多在5000元至6000元，在市场竞争中压力不小。

## 做法（已经发生的）
1. 拉萨市文化和旅游局、拉萨市旅游警察支队、曲水县文化和旅游局、曲水县市场监管局、曲水县卫生健康委员会等部门开展突击检查，记者跟随。
2. 拉萨市文化执法队经查，西藏华茂旅行社存在擅自增加行程点位，将共计18名游客带至西藏堆孜医药研发有限公司参观。
3. 拉萨市文化执法队经查，现场存在工作人员面向游客开展保健品推介、药品推销等行为，涉嫌非法推介药品、疑似非法诊疗。
4. 拉萨市旅游警察支队已封存全部监控。
5. 拉萨市旅游警察支队对屡教不改者建立重点监管名单，深挖幕后推手。
6. 曲水县已全面启动后续核查，深挖“组团带客—进店推销—高额返点—诱导消费”的全链条违法事实。
7. 曲水县文旅局局长赐仁拉姆介绍，全县正着力构建全链条监管机制，线上联合网信部门、短视频平台清理低价引流违规账号。
8. 曲水县文旅局局长赐仁拉姆介绍，线下压实乡镇、派出所线索摸排责任，建立异常停靠快速移送机制。
9. 曲水县文旅局局长赐仁拉姆介绍，对所有新增涉旅主体前置合规约谈，纳入常态化重点监管台账，破除“运动式”执法困境。

## 争议 / 难点
- 部分违规购物场所与导游形成深度利益捆绑，成为日常监管的“盲区”。
- 当地某旅行社负责人刘先生（化名）观察，部分购物场所与监管部门“躲猫猫”，选择非工作时间或隐蔽地点接待游客，有的不悬挂招牌，专门承接与特定旅行社绑定的团队。
- 业内人士透露，高额利润驱动违规者频繁更换经营主体、转移地点。
- 刘先生表示，此前专项整治虽见成效，但个别场所换上“新马甲”悄然复业，不仅冲击了合规经营者，更可能伤及西藏旅游的品牌形象。
- 旅游市场整治具有长期性、复杂性。

## 建议 / 主张（还没发生的）
1. 多名从业者呼吁，进一步明确规则，坚决取缔违规经营，维护公平竞争环境。
2. 曲水县副县长德央表示，针对虚增路线、无证问诊、无证售药等违法违规行为，将依法固定证据、从严立案，并面向社会公开通报。
