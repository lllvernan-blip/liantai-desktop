# 综应练习台

一个零依赖、单文件的 AI 原生综应 A 练习工具。它覆盖公文写作、归纳概括、综合分析、提出对策和案例实务五类训练，提供学习卡、作答、AI 阅卷、采分点对照、画像和自适应推送。

## 运行

项目不需要安装依赖，也没有构建步骤。

1. 直接双击打开 [`综应练习台.html`](./综应练习台.html) 即可浏览离线界面。
2. 在右上角「设置」中填写服务商、Base URL、模型和 API Key 后，才能出题和阅卷。
3. 如果浏览器拦截 `file://` 的跨域请求，在项目目录运行：

   ```powershell
   python -m http.server 8000
   ```

   然后打开 `http://localhost:8000/综应练习台.html`。

API 请求只发往设置里的 Base URL。API Key 保存在当前浏览器的 `localStorage` 中。导出备份会序列化完整状态，分享 JSON 前请检查并删除 `settings.apiKey`。

## 自检

```powershell
node tests/run.mjs
```

测试脚本会抽取主 HTML 中唯一的 `<script>`，配合 `tests/dom-stub.js` 和 `tests/assertions.js` 在 Node.js 中运行，不需要浏览器或 npm。修改 HTML 内的业务脚本、状态键、渲染结构或测试桩后，都要跑一次完整自检。

## 文件

- `综应练习台.html`：唯一应用入口，包含全部 HTML、CSS 和 JavaScript。
- `tests/run.mjs`：自检入口。
- `tests/dom-stub.js`：供 Node.js 自检使用的最小 DOM 和 `localStorage` 桩。
- `tests/assertions.js`：纯函数、渲染、存储、异步降级、调度和划线功能断言。
- `AGENTS.md`：后续协作者的项目边界和验证约定。

## 数据

应用使用浏览器本地存储，不建立服务端数据库：

- `gw_state`：设置、画像、练习历史、学习卡缓存和笔记。
- `gw_draft`：按题目签名保存的未提交作答草稿，最多 8 份。
- `gw_marks`：按题目签名保存的材料字符级划线，最多 8 份。

设置、画像和导入导出是弹层；练习流程保持在同一文档舞台内。AI 出题和阅卷失败时，应保留当前题目和答案，不把失败结果写进历史。

## 维护提示

这是有意保持的单文件、零依赖架构。除非明确决定迁移，不要拆分入口或引入构建体系。主脚本由测试运行器从 `<script>` 中抽取，改变脚本标签结构时要同步调整 `tests/run.mjs`。

总分口径：题目满分来自题目自身的 `question.score`，采分点（`keyPoints`）是带分值的子项，分值之和等于题目满分；阅卷按覆盖程度落三档给分，总分即各子项实得分之和，另折合百分制存为 `grade.total` 供画像跨题比较。各维度分只用于画像诊断，不参与总分。若阅卷列出的子项合计与题目满分不一致，界面会明示，并只按已列出的子项计分。

新增或修改状态字段时，要考虑旧 `localStorage` 和导入备份的默认值合并与迁移；不要直接删除已有键。涉及用户答案、草稿、历史、划线、AI 请求和调度的改动，必须补对应断言并跑全量自检。
