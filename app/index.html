还没有 API Key？四步拿到（推荐 DeepSeek，几分钱练一次）
① 注册：浏览器打开 platform.deepseek.com，用手机号注册并登录。 ② 创建 Key：左侧「API keys」→「创建 API key」，复制生成的 sk- 开头字符串（只显示这一次）。 ③ 充值：账户里充少量余额即可用（按用量计费，练一次题大约几分钱）。 ④ 回到这里：Key 粘进上面的输入框 → 点下面「拉取模型列表」选一个模型 → 关掉设置，开始练。
填上 Key 后可拉取候选名单，也可以直接输入模型名。
