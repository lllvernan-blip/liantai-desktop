# 材料规范（素材从哪来 · 出题凭什么）

这份文件回答一个问题：**练习题的材料，凭什么信得过？**

它管三件事：材料从哪来、怎么提炼、出题时凭什么。**不管界面、不管引擎调度、不管判分口径**——那些在别处。

写法沿用 `docs/题型规范.md` 的规矩：**每个判断后面跟着它的依据**。依据分三档，正文里逐条标明：

- **【官方】** 来自官方文件原文（附章节号或 URL）
- **【实测】** 来自本机真跑出来的结果（附命令产出）
- **【自定】** 没有外部依据，是本项目自己定的规矩——**必须标出来**，不许伪装成规范

---

## 一、先说一件必须说清的事：没有官方依据可依

**【官方】官方大纲对「材料」几乎不着一字。**

- 事业单位《综合应用能力(A类)》2026 年版大纲，唯一涉及材料的一句在 §4.1.2.3：「试卷以主观性试题为主，由背景材料和任务组成。任务主要涉及事业单位管理岗位典型的工作，如观点归纳、资料分类、草拟信函、应急处理、联络通知等。」——**全文没有对材料的性质、来源、真实性、篇幅作任何规定**。（原文 PDF：人社部人事考试中心 2026 年版，宝鸡市人社局镜像 `https://rsj.baoji.gov.cn/col1283/col1284/202602/P020260214341950623049.pdf`）
- 国考《申论》大纲：「『给定资料』是需要报考者阅读的有关材料，是完成『作答要求』的基础。『给定资料』所反映的是经济社会发展中的某些事例，对经济、政治、文化、社会、生态等方面都有可能涉及。」——**同样无来源、真实性、篇幅规定**。（国家公务员局 2025 年度专题站）
- 省考（北京市 2026 年度）措辞与国考一致，「给定材料」，同样无规定。

**【官方】也没有公开的官方命题说明。**

- 官方文本里只有**面试**的命题规范：《公务员录用面试组织管理办法（试行）》（人社部发〔2015〕93 号）第八条「试题命制单位应按照命题规范开展试题命制、征集、评审和组配，编制面试题本。」
- 教育部有《高等教育自学考试命题工作规定》——**说明「命题工作规定」这种文书形式是存在的**，但公务员/事业单位**笔试**的同类文件从未公开。

**【实测】真题材料溯源：没有权威版本。**

- 没有找到学术层面的系统性溯源研究。只有考生/培训机构整理的零散清单（如知乎某答主列出 2010 年国考材料出自央视《经济半小时》、《南风窗》等），条目少、无交叉验证，**不能当事实源**。

**由此定下一条硬口径：**

> **不许在任何地方（代码注释、文档、界面文字、更新日志、对外说明）声称本项目「对标官方命题规范」或「按官方命题标准出题」。官方没有公开的笔试命题规范，这么说是编的。**

**能引官方的地方只有考试大纲对题型与能力的规定**（已写进 `docs/题型规范.md`）。材料这一块，**我们只能自定规矩，并且承认是自定的**。

**【自定】下面所有条目，凡没有【官方】标记的，都是本项目自定的规矩。**

**依据强度排下来：能引大纲的引大纲（题型/能力）→ 能对真题的对真题（形态/结构）→ 剩下的自定并标出。** 这条排序本身就是规矩：**越往上越硬，别拿自定的当官方使。**

## 二、两种材料模式，必须分开，不许混

出题有两条路，**它们的规矩是相反的**，写在一个 prompt 里必然打架。

| | **自编模式**（现状） | **有据模式**（本规范新增） |
| --- | --- | --- |
| 材料来源 | 模型现场编 | 素材库里抓来的真实材料 |
| 事实要求 | **必须虚构**，数字不指向任何真实来源 | **关键事实要有出处**，能回链 |
| 地名机关 | 一律虚化（某市/某县） | 同样虚化 |
| 政策文号 | **不许出现** | 同样不许出现在题面上 |
| 界面标记 | 无 | 「据材料」 |
| 出处留痕 | 无 | 有（只留痕，不显示） |

**为什么必须分开**：现在 `app/index.html` 的 `matSpec`（`gen()` 内）写死了「数字只作情境设定，不指向任何真实来源」——那是为自编模式立的规矩。有据模式要走同一张 `matSpec` 的话，这条不移除、或者半移半留，都会产出一份自相矛盾的 prompt。

**判定与切换**：`matSpec` 那两条按模式分支产出，**同一分支内不许出现相反要求**。这是硬约束。

## 三、一手材料的定义与来源

**一手 = 权威发布方的原文。**
**二手 = 新闻报道**——记者已经替你选过、概括过、解读过了。

**【自定】正确的关系不是「只用一手」，而是分工：**

```
新闻稿（发现线索：什么事值得出题）
    ↓
一手材料（确认事实：数字、政策原文、做法到底是什么）
    ↓
事实骨架（每条带出处）
    ↓
出题
```

**只走新闻稿那条路（现状）的问题**：新闻稿本身就可能转述失真，我们再从新闻稿里抽「事实」，等于在二手之上再加工一次，**错误会累积，而且无处可查**。

### 【实测】一手材料的可达性（2026-10-14 本机实测）

| 材料类型 | 入口 | 结果 |
| --- | --- | --- |
| **国务院政策文件** | `sousuo.www.gov.cn/search-gov/data?t=zhengcelibrary_gw&q=关键词&searchfield=title&n=&p=` | ✅ **6222 条**，含标题/文号/发布日期/正文 URL |
| **国务院部门文件** | 同上，`t=zhengcelibrary_bm` | ✅ **12801 条** |
| **国务院公报** | 同上，`t=zhengcelibrary_gb` | ✅ **15042 条** |
| **政策原文正文** | 逐条抓 `https://www.gov.cn/zhengce/zhengceku/.../content_XXX.htm` | ✅ 实测一篇 26 段 / 2890 中文字，标题抬头正文完整 |
| **地方政府网站** | 直接抓列表页 | ✅ 平江、岳阳、杭州、深圳四例全通，静态路径、政策公开类链接数十条 |
| **部委网站** | 直接抓 | ✅ 民政部、农业农村部首页与文章页均通 |
| **统计局发布页/公报** | `stats.gov.cn/sj/zxfb/`、`/sj/tjgb/ndtjgb/` | ✅ 可抓 |
| 国家法律法规数据库 `flk.npc.gov.cn` | `/api/`（POST） | ⚠️ 接口存在，HTTP 方法与参数**未在本机实测通过** |
| 统计局数据库接口 | `data.stats.gov.cn/easyquery.htm` | ❌ 403（UrlACL） |
| 中国政府网政策文件库**检索页** | `zhengce/zhengceku/` | ❌ 403；**但 JSON 接口可用**（见上） |

**两条实测踩出来的坑：**

1. **子库名不是 `zhengcelibrary`，是 `zhengcelibrary_gw` / `_bm` / `_gb`。** 用错子库名时接口**返回 `code:200` 但 `totalCount:0`**——不报错，静默给空结果。**任何抓取都要断言「拿到了条数」**，别把「空」当「没搜到」。
2. **检索词要带 `searchfield=title` 才生效**，不带时返回的是该子库的全量（1193→1656 这种数），看着有数据其实没按关键词筛。**别被 total 数字骗了，要核对返回条目里真的含关键词。**

**字段以栏目分**：不同栏目的文章类型差别很大。求是网「要闻」几乎全是领导人活动动态，**不是「某地做法」类材料**；适合出题的做法类文章在评论、理论、地方等栏目。**抓取要按栏目定向，不能按站点一把抓。**

## 四、选材：什么材料能进库

**【自定】** 素材库**不是档案馆，是选题池**。进不了库的材料，抓了也是浪费。

入库前必须过一道判断：**这篇能出什么题？**

一篇材料有价值，至少满足一条：

- **有矛盾**——有问题、有争议、有不同做法（分析题、对策题的原料）
- **有做法**——具体的措施与步骤（归纳题、公文题的原料）
- **有数据**——可核的数字（材料密度的基础）
- **有立场**——不同主体态度不一（综合分析的原料）

**只有成绩、只有表态、只有会议消息的，不入库。**

**「争议 / 难点」栏不许空**：一篇通篇只有成效的材料，只能出概括题，出不了分析题。没有难点的文章，**要么补上它的难点，要么不进库**。

**【自定】判据**：一份材料至少要能支撑 **2 道题**（不同题型），否则单题成本过高，不值得留在库里。

## 五、提炼：事实骨架怎么写

**【自定】核心规矩：抽条目，不做概括。**

摘要会丢事实。一篇文章讲了 5 个案例，写摘要的模型会挑 3 个说「等地大力推行多种举措」——**另外 2 个永久消失**，而原文不存，回头都找不回来。

骨架格式（每篇一份 markdown）：

```markdown
# <标题>

来源：<一手材料的 URL>
发布：<发布日期>
文号：<有则写，无则留空>
抓取：<日期>

## 背景
- <事实条目，一条一个事实，带数字带限定语>

## 做法
1. <做法> —— <对应数据>

## 成效
- <数据>

## 争议 / 难点
- <这一栏不许空>
```

**【自定】三条硬要求：**

1. **一条只写一个事实**。与 `keyPoints[].need` 同一条道理（见 `AGENTS.md` 学习闭环节）：一条塞了并列要件，后面就没法核。
2. **保留带钱、带比例、带时间的数字**。这些是材料密度的来源，也是**唯一能核的东西**。
3. **允许啰嗦，不许归纳**。「多地推行多种举措」这种句子等于什么都没写。

**【自定】长度 600–1500 字**。更短撑不起 2 道题（快判一道题就要吃掉 120–200 字材料）。

**存什么**：**只存骨架，不存原文。** 理由——材料本来就要虚化成「某市/某县」，原文的血肉在这一步就被抹掉了；不存原文还顺带避开了转载他人全文的问题。**代价是提炼错了就回不去**，所以第四节的选材关和第六节的核验不能省。

## 六、出题：有据模式下的规矩

**【自定】沿用现有口径的部分**（不变）：

- 地名与机关一律虚化（某市/某县/某镇/某社区，或 A 市/A 县），**不自造「江城市」这类看着像真的名字**
- 题面上不出现真实的政策、法规、文件的名称与文号
- 材料长度、作答上限走 `docs/题型规范.md` 那张表——**唯一口径，不许 model 自己定**

**【自定】有据模式新增的部分**：

- **关键事实必须能回链**。骨架里每个数字、每项政策的出处，在出题时跟着走，落在题目记录的元数据里。
- **出处只留痕，不显示**。界面上只有一个小标记「据材料」，**不写来源、不写媒体名、不写文号**。理由：真考不给材料标出处，标了反而出戏；材料已虚化，写出来处也没多大信息量。留痕的价值在**追责**，不在展示。
- **不许在骨架之外补事实**。模型可以改写措辞、可以调整结构、可以合并同类事实，**但不能新增骨架里没有的数字或做法**。

## 七、可核验性：凭什么说它是对的

**【自定】四个检验，从便宜到贵：**

1. **抽样回链**（每批必做）
   随机抽 N 条骨架事实，回到一手材料核对。**报结果要连「抽了几条、错几条」一起报**，只报百分比等于没说。错误率超过 10% 就整批重做。

2. **双源交叉**（关键数字必做）
   材料里的数字，去**官方数据**对一次。对不上的，**要么改数、要么删掉这个事实**，不许「大致对得上」就放过。

3. **独立重做**（换模型）
   换一个模型，从同一份一手材料重新提炼一遍骨架。**两份一致的部分可信，分歧的部分标记为可疑**——这是最省力的可疑点探测器。

4. **人类试做**（重要批次做）
   出的题让人真做一遍，检查：答案唯一吗？选项有歧义吗？材料够不够回答？**这是最硬的检验，也是唯一能抓住「题目本身有问题」的手段**——前三条都只能验证事实，验证不了题。

**【自定】真题对标**：真题是唯一可对标的外部标准（官方没有命题规范可依，见第一节）。对标的是**形态**：材料长度、题量、能力分布、设问方式。**不是对标具体内容。**

## 八、还没解决的

**如实列在这里，不许当成已解决：**

1. **没有官方命题规范可依**。第一节已说明。这意味着这套流程**天然只能自称「练习仿真」，不能自称「对标官方」**。
2. **真题溯源没有权威版本**。想检验「我们的材料像不像真题的材料」，**没有现成的对照物**，只能自己拿真题文本反查。这条路没走过。
3. **法律法规库的接口没打通**。`flk.npc.gov.cn/api/` 存在，但 HTTP 方法与参数未经本机实测，**在没验通之前不许写进代码**。
4. **统计局数据库接口 403**。发布页与公报页可抓，**逐项取数的接口走不通**——需要数字时可能得从公报正文里抽。
5. **提炼环节的误差没有量化过**。抽样回链这条规矩定了，**但一次都没真跑过**，10% 这个阈值是估的。
6. **材料的时效判定没有规矩**。政策文件会被新文件替代、数据会更新，**什么算「过期」现在没定义**。
