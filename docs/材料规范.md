# 材料规范（素材从哪来 · 出题凭什么）

这份文件回答一个问题：**练习题的材料，凭什么信得过？**

它管三件事：材料从哪来、怎么提炼、出题时凭什么。**不管界面、不管引擎调度、不管判分口径**——那些在别处。

写法沿用 `docs/题型规范.md` 的规矩：**每个判断后面跟着它的依据**。依据分三档，正文里逐条标明：

- **【官方】** 来自官方文件原文（附章节号或 URL）
- **【实测】** 来自本机真跑出来的结果（附命令产出）
- **【自定】** 没有外部依据，是本项目自己定的规矩——**必须标出来**，不许伪装成规范

---

## 一、先说一件必须说清的事：没有官方依据可依

**【官方】官方大纲对「材料」几乎不着一字。**

- 事业单位《综合应用能力(A类)》2026 年版大纲，唯一涉及材料的一句在 §4.1.2.3：「试卷以主观性试题为主，由背景材料和任务组成。任务主要涉及事业单位管理岗位典型的工作，如观点归纳、资料分类、草拟信函、应急处理、联络通知等。」——**全文没有对材料的性质、来源、真实性、篇幅作任何规定**。（原文 PDF：人社部人事考试中心 2026 年版，宝鸡市人社局镜像 `https://rsj.baoji.gov.cn/col1283/col1284/202602/P020260214341950623049.pdf`）
- 国考《申论》大纲：「『给定资料』是需要报考者阅读的有关材料，是完成『作答要求』的基础。『给定资料』所反映的是经济社会发展中的某些事例，对经济、政治、文化、社会、生态等方面都有可能涉及。」——**同样无来源、真实性、篇幅规定**。（国家公务员局 2025 年度专题站）
- 省考（北京市 2026 年度）措辞与国考一致，「给定材料」，同样无规定。

**【官方】也没有公开的官方命题说明。**

- 官方文本里只有**面试**的命题规范：《公务员录用面试组织管理办法（试行）》（人社部发〔2015〕93 号）第八条「试题命制单位应按照命题规范开展试题命制、征集、评审和组配，编制面试题本。」
- 教育部有《高等教育自学考试命题工作规定》——**说明「命题工作规定」这种文书形式是存在的**，但公务员/事业单位**笔试**的同类文件从未公开。

**【实测】真题材料溯源：没有权威版本。**

- 没有找到学术层面的系统性溯源研究。只有考生/培训机构整理的零散清单（如知乎某答主列出 2010 年国考材料出自央视《经济半小时》、《南风窗》等），条目少、无交叉验证，**不能当事实源**。

**由此定下一条硬口径：**

> **不许在任何地方（代码注释、文档、界面文字、更新日志、对外说明）声称本项目「对标官方命题规范」或「按官方命题标准出题」。官方没有公开的笔试命题规范，这么说是编的。**

**能引官方的地方只有考试大纲对题型与能力的规定**（已写进 `docs/题型规范.md`）。材料这一块，**我们只能自定规矩，并且承认是自定的**。

**【自定】下面所有条目，凡没有【官方】标记的，都是本项目自定的规矩。**

**依据强度排下来：能引大纲的引大纲（题型/能力）→ 能对真题的对真题（形态/结构）→ 剩下的自定并标出。** 这条排序本身就是规矩：**越往上越硬，别拿自定的当官方使。**

## 二、两种材料模式，必须分开，不许混

出题有两条路，**它们的规矩是相反的**，写在一个 prompt 里必然打架。

| | **自编模式**（现状） | **有据模式**（本规范新增） |
| --- | --- | --- |
| 材料来源 | 模型现场编 | 素材库里抓来的真实材料 |
| 事实要求 | **必须虚构**，数字不指向任何真实来源 | **关键事实要有出处**，能回链 |
| 地名机关 | 一律虚化（某市/某县） | 同样虚化 |
| 政策文号 | **不许出现** | 同样不许出现在题面上 |
| 界面标记 | 无 | 「据材料」 |
| 出处留痕 | 无 | 有（只留痕，不显示） |

**为什么必须分开**：现在 `app/index.html` 的 `matSpec`（`gen()` 内）写死了「数字只作情境设定，不指向任何真实来源」——那是为自编模式立的规矩。有据模式要走同一张 `matSpec` 的话，这条不移除、或者半移半留，都会产出一份自相矛盾的 prompt。

**判定与切换**：`matSpec` 那两条按模式分支产出，**同一分支内不许出现相反要求**。这是硬约束。

## 三、一手材料的定义与来源

**一手 = 权威发布方的原文。**
**二手 = 新闻报道**——记者已经替你选过、概括过、解读过了。

**【自定】正确的关系不是「只用一手」，而是分工：**

```
新闻稿（发现线索：什么事值得出题）
    ↓
一手材料（确认事实：数字、政策原文、做法到底是什么）
    ↓
事实骨架（每条带出处）
    ↓
出题
```

**只走新闻稿那条路（现状）的问题**：新闻稿本身就可能转述失真，我们再从新闻稿里抽「事实」，等于在二手之上再加工一次，**错误会累积，而且无处可查**。

### 【实测】一手材料的可达性（2026-10-14 本机实测）

| 材料类型 | 入口 | 结果 |

| **国务院部门文件** | 同上，`t=zhengcelibrary_bm` | ✅ **12801 条** |

1. **子库名不是 `zhengcelibrary`，是 `zhengcelibrary_gw` / `_bm` / `_gb`。** 用错子库名时接口**返回 `code:200` 但 `totalCount:0`**——不报错，静默给空结果。**任何抓取都要断言「拿到了条数」**，别把「空」当「没搜到」。
2. **检索词要带 `searchfield=title` 才生效**，不带时返回的是该子库的全量（1193→1656 这种数），看着有数据其实没按关键词筛。**别被 total 数字骗了，要核对返回条目里真的含关键词。**

**编码（2026-10-15 重测，修正了原先那句「全部 UTF-8」）**：上述可用的站里，**人民网社会法治频道是 UTF-8**，但它家**时政频道是 GBK（`gb2312`）**——从前那份记录写的是「以上全部 UTF-8，没有 GBK 坑」，实测不成立。所以抓取必须**从响应里读 charset 再解码**，不能一律按 UTF-8 解，否则标题会静默变成乱码（页面照常 200，看不出错）。

**【实测】新华网的坑比原先记的更严重**（2026-10-15）：它不是“时而给旧内容”，而是地方频道**整页都停在 2022 年 7 月**（标题、链接、日期全对，内容全旧，HTTP 200）。拿它出题会发“看着很新、其实是三年前”的材料。**这类“静默过期”比报错危险**——不报错就发现不了。所以新华系一律不用，除非拿到时间戳可核的接口。

**【自定】找“某地做法”类材料看栏目，不看站点。**2026-10-15 实测：人民网社会法治频道里，**《金台视线》《人民直击》这两个栏目正是要的东西**（有矛盾、有做法、有数据、有立场四条全占）；同页的图片新闻（“某地：采摘菊花 供应市场”这类）正文不到两百字，**一条都出不了题**。实测一屏 11 条里 5 条是图片新闻，**所以“取前 N 篇”这个做法在新闻源上根本不成立**：要按正文长度往后取（见 `tools/material-pool.mjs` 的 `MIN_BODY`）。

**【实测】合格率差在栏目，不在站点**（同日，带数字）：

| 源 / 栏目 | 抓到的篇数 | 合格率 |
| --- | --- | --- |
| 人民网·**人民直击**栏目页 | 7 | 接近全部 |
| 人民网·财经 / 教育 / 健康频道首页 | 13 | 约 1/4（其余全是成就稿） |
| 人民网·社会法治「说法专栏」 | — | 全部是案件警示，0 |

于是结论是**不要把频道首页当源**：首页是宣传口。同一个站里，“调查报道类栏目”与“频道首页”的合格率差四五倍。

**字段以栏目分**：不同栏目的文章类型差别很大。求是网「要闻」几乎全是领导人活动动态，**不是「某地做法」类材料**；适合出题的做法类文章在评论、理论、地方等栏目。**抓取要按栏目定向，不能按站点一把抓。**

## 四、选材：什么材料能进库

**【自定】** 素材库**不是档案馆，是选题池**。进不了库的材料，抓了也是浪费。

入库前必须过一道判断：**这篇能出什么题？**

一篇材料有价值，至少满足一条：

- **有矛盾**——有问题、有争议、有不同做法（分析题、对策题的原料）
- **有做法**——某个主体为了解决问题采取的措施（归纳题、对策题、公文题的原料）
- **有数据**——可核的数字（材料密度的基础）
- **有立场**——不同主体态度不一（综合分析的原料）

**【实测】「成就稿」这条靠「有没有成绩」是拦不住的，得换个问法**（2026-10-15）：

原文写的是「只有成绩、只有表态、只有会议消息的不入库」。实测一篇《抹茶+咖啡，抓住年轻人的心和胃》（1873 字）顺利进来了——因为它确实有 12 条做法、2 条背景，模型觉得「不至于只有成绩」。而它抽出来是 **背景 2 / 做法 12 / 成效 36 / 难点 1**，是典型的成绩宣传稿比例。

**问题出在判据的方向**：不是「有没有成绩」，而是「**这篇里有没有一个还没解决的问题**」。具体怎么判：

1. 把它记下来的事实分成「问题/背景」与「结果/成效」两堆。结果那堆明显压过问题那堆（成效十几条、背景只剩一两条），且通篇找不到一个还没办妥的环节、一处不同意见、一点遗留短板——即成就稿。
2. 换一句话自问：**这篇里有没有「谁正在为某件事发愁」？** 没有就是成就稿。

**别误伤**：一篇材料成效很多不要紧，只要它还同时写着一个没解决的问题（成效背后还有短板、还有争议、还可能反弹），就算合格。**拦的是「只有结果没有问题」，不是「结果比较多」。**

**【自定】成就不等于没用，但它出不了练习需要的题。** 用得上的是「一个问题局面 + 别人怎么应对」，成绩单里没有局面。

**【实测】「有做法」这条最容易判错，得单独画一条线**（2026-10-15）：做法指的是**某个主体为了解决问题主动采取的措施**；反过来，**案子怎么发生的、谁骗了谁、事件经过，一律不算做法**。转折点是 2026-10-15 实测的一篇反诈警示稿《租车转手赚快钱？小心黑恶势力陷阱》（771 字）：它「有矛盾（李某翻脸）、有做法（引诱租车押车）、有数据（5 万、32 万）」表面上三条全占，提炼出来却是「引诱租车 / 质押变现 / 翻脸 / 截人 / 逼签购车条 / 拘禁十天」——**全是犯罪过程**。一篇文章读完只能感慨一句「小心陷阱」、学不到任何办法的，不入库。

**两道可执行的自检**：
1. **把这条里的主体名换掉，还剩不剩一个别人能借鉴的办法？** 换掉就没了，说明它只是事件经过。（同 AGENTS.md 的划线判据：把句子里所有标识符去掉，还剩不剩一个可执行的判断。）
2. **这篇能不能出对策题？** 不能出对策题的，就算有矛盾、有数据，也只算半篇。

**入库要有矛盾或难点，这道判断做在选材这一步**：一篇通篇只有成效的材料，只能出概括题，出不了分析题。文章里真没有的，**换一篇，不是编一个**。提炼那一步的规矩正好相反——**宁缺勿造**（见第五节）。

**【自定】判据**：一份材料至少要能支撑 **2 道题**（不同题型），否则单题成本过高，不值得留在库里。

## 五、提炼：事实骨架怎么写

**【自定】核心规矩：抽条目，不做概括。**

摘要会丢事实。一篇文章讲了 5 个案例，写摘要的模型会挑 3 个说「等地大力推行多种举措」——**另外 2 个永久消失**，而原文不存，回头都找不回来。

骨架格式（每篇一份 markdown）：

```markdown
# <标题>

来源：<一手材料的 URL>
发布：<发布日期>
文号：<有则写，无则留空>
抓取：<日期>

## 背景
- <事实条目，一条一个事实，带数字带限定语>

## 做法（已经发生的）
1. <某个主体为了解决问题已经做了什么> —— <对应数据>

## 成效
- <数据>

## 争议 / 难点
- <宁缺勿造：凑不出真实难点就只写一句「原文未提及」>

## 建议 / 主张（还没发生的）
1. <谁提出该怎么做 —— 原文里还没发生>
```

**【2026-10-15 加栏】「做法」与「建议」必须分栏。** 起因是出题那一步实测出来的：一篇评论文章通篇是「要丰富……」「专家建议……」，被当成做法收进了骨架；到有据出题时，这些建议整段被抄进材料，而题干问的是「提出改进建议」——**答案现成躺在材料里，抄一遍就得分**。

分栏的判据一句话：**这件事发生了没有。**

- **做法**——《已经发生的》某个主体为了解决问题采取的措施（「瑞丽市率先公布了阶梯式收费标准」）
- **建议 / 主张**——谁提的、但还没做（「聂鑫认为，应破解部门治理壁垒」「刘汉华建议各地制定管控政策前先摸排」）

分栏后的实测对比（同一批 11 篇、同一档位）：

| 篇 | 做法 | 建议 |
| --- | --- | --- |
| 从假日消费看化解供强需弱（评论） | 26 → **1** | 23 |
| 擦边营销为何屡禁不止（调查） | 12 → **2** | 21 |
| 沼液还田，施肥不当致污染（调查） | 17 → **3** | 13 |
| 住宅楼里办民宿，该怎么管（调查） | 18 → **5** | 11 |
| 老字号，成为年轻人心头好（企业做法） | 31 → **39** | 6 |

分完以后「做法」一栏才是真的做法：**调查与评论类文章本来就没多少已成之事**，之前那几十条全是专家怎么说。

**【自定】三条硬要求：**

1. **一条只写一个事实**。与 `keyPoints[].need` 同一条道理（见 `AGENTS.md` 学习闭环节）：一条塞了并列要件，后面就没法核。
2. **保留带钱、带比例、带时间的数字**。这些是材料密度的来源，也是**唯一能核的东西**。
3. **允许啰嗦，不许归纳**。「多地推行多种举措」这种句子等于什么都没写。

**【实测】五栏各归各位，一条事实只准出现在一栏**（2026-10-15）：

- **背景**只放「事情为什么会成问题」——放行动过程与现场细节就是串栏
- **做法**只放「**已经发生的**、为了解决问题做了什么」——放当事人之间发生了什么、放还没发生的建议都是串栏（同第四节）
- **成效**只放「这么做之后出现了什么可核的结果」——**把做法换个说法重抄一遍不算成效**
- **难点**只放「为什么这事不好办」——放已经解决了的旧问题就是串栏
- **建议**只放「还没做、被提出来的主张」——**已经做了的归做法**

**同一件事在「做法」和「成效」里各写一遍，是这个环节最严重的错**：出题时会把它当成两个采分点，一份答卷答了一条就被算成答了两条。**可见的判据：两栏里有没有逐字相同的句子？**

**【实测】主体、语气、时间、范围都不许改写（规则 11 的由来）。** 四轮抽样回链里剩下的错全是同一类：主体被上移一层（「相关工作人员说」→「工作室宣称」、「个人观点」→「有观点认为」）、两件事被并成一件（甲地案 + 乙地案 → 「套取资金」）、**语气被拉高一档**（「在很多人的印象里」→「很多人认为」、「很纳闷」→「质疑」、「还可参与」→「积极参与」）。它不是编造，字面上看着都有依据；但出题时会变成采分点，**答对了的人反而被扣分**。规矩写死了四句话：① 主体照原文写，不许上移一层；② 语气与程度不许拉高，拿不准就照抄原词；③ 时间与范围不许丢；④ 不同主体、不同地区、不同案件的事不许并成一条。
注意方向：这条管的是**向强改**（说得比原文满）。反过来，并列的事拆成几条、一条只取并列原因中的一个，**都是对的**（第五条规矩）。这个方向差异曾经把「原子化」误判成「遗漏了并列表述」，白噪一轮。

**【实测】五栏都可以空，空着不扣分，凑数才扣分。**（同日）模型的默认行为是**把手里所有事实分进几个桶，不管合不合**；只说「宁缺勿造」它不听，因为它感觉不到自己能丢东西。新闻里大量材料**本来就没有可核的成效**（整治还在进行中），也**本来就没有真实的难点**（读者看得出难，原文并未写出）。逐栏自检要具体到「该丢掉什么」，否则这段话落不了地：

- 「背景」删掉**行动过程与现场细节**（「记者跟随执法」「执法人员抵达时大门紧锁」）
- 「做法」删掉**当事人之间的往来**（谁引诱谁、谁翻脸、谁逼谁签条），也删掉**建议**（「要丰富……」「专家建议……」）
- 「成效」删掉**执法发现与原文事实**（「查获 POS 机」「无法出示执业证明」「营业执照注册于 7 月 16 日」「签过承诺书」）——发现不等于收效
- 「难点」删掉**调查见闻**（「地接人员先问是否本地人」「凭参观证进场」「有人望风」）——那是怎么查出来的，不是难在哪里的机制障碍

**【实测】这条规矩的落地效果**（2026-10-15，同一篇文章、同一档位、逐轮收紧）：

| 轮次 | 条数 | 背景 / 做法 / 成效 / 难点 | 问题 |
| --- | --- | --- | --- |
| 第一轮 | 67 | 27 / 21 / 9 / 10 | 背景栏装了暗访过程；成效栏是做法复述 |
| 收紧「做法 ≠ 事件经过」后 | 46 | 11 / 11 / 10 / 14 | 背景干净了，成效与做法仍逐字重复 |
| 加「一栏只准一次」后 | 41 | 7 / 13 / 10 / 11 | 不再重复，但难点栏换成了暗访细节 |
| 加逐栏自检后 | 28 | 6 / 13 / **0** / 9 | 模型自己判定这篇没有可核成效 |

**成效那栏归零不是失败，是这一轮唯一真正对的输出**——正文本就没写贯彻落实后的结果。

**【实测】不设字数上限，判据是「每条事实能不能出题」。** 抽条目不概括会把骨架拉长——实测一份近 8000 字的规则型文件（民政部《城乡三级养老服务网络建设管理指引》，126 段），提炼出 **4900 字、147 条**。这是正常的，压不动也不该压：那种文件几乎每段都是独立规则，一概括就丢规则。该拦的是另外两样——**出不了题的句子**（评价、意义、表态、套话）和**同一件事在几栏里重复出现**。

下界是硬的：**撑不起 2 道题（不同题型）的骨架，并掉或重选材料**——快判一道题要吃掉 120–200 字材料。

**【实测】「争议 / 难点」栏宁缺勿造。** 这一栏最容易出的错，是把上一栏的做法和要求搬过来充数。实测第一遍产出：模型在这栏塞了 14 条「不符合的要进一步完善」「要加强指导调度」这类**做法与要求**，最后自己补一句「原文未提及……具体难点」——**两头都占了**，既填满了栏，又声明原文没有。所以规矩写死：**凑不出真实难点，就只写一句「原文未提及」**，不许为了填栏换一批句子。这一栏空着是信息，塞满假的是污染。

**【实测】元数据与正文分开给。** 抓取接口给的发布日期、文号、栏目名是**元数据**，不是材料事实。实测把它们跟正文混在同一段里递进去，模型把「文件发布日期为 2026 年 7 月 8 日」当成骨架的一条事实记了下来——正文里根本没有这句话，回链核对判「原文没有」（那篇文件的落款日期是 5 月 29 日）。**元数据只填骨架的头部（来源 / 发布 / 文号 / 抓取），正文单独一段给**，prompt 里明说「只从正文抽事实」。

**存什么**：**只存骨架，不存原文。** 理由——材料本来就要虚化成「某市/某县」，原文的血肉在这一步就被抹掉了；不存原文还顺带避开了转载他人全文的问题。**代价是提炼错了就回不去**，所以第四节的选材关和第六节的核验不能省。

## 六、出题：有据模式下的规矩

**【自定】沿用现有口径的部分**（不变）：

- 地名与机关一律虚化（某市/某县/某镇/某社区，或 A 市/A 县），**不自造「江城市」这类看着像真的名字**
- 题面上不出现真实的政策、法规、文件的名称与文号
- 材料长度、作答上限走 `docs/题型规范.md` 那张表——**唯一口径，不许 model 自己定**

**【自定】有据模式新增的部分**：

- **关键事实必须能回链**。骨架里每个数字、每项政策的出处，在出题时跟着走，落在题目记录的元数据里。
- **出处只留痕，不显示**。界面上只有一个小标记「据材料」，**不写来源、不写媒体名、不写文号**。理由：真考不给材料标出处，标了反而出戏；材料已虚化，写出来处也没多大信息量。留痕的价值在**追责**，不在展示。
- **不许在骨架之外补事实**。模型可以改写措辞、可以调整结构、可以合并同类事实，**但不能新增骨架里没有的数字或做法**。
- **回链核对是这个约束的落地动作**（2026-10-15 加）：每生成一道题，就把材料逐句回链到骨架比一遍，报「加料几条」。光在 prompt 里写一句「不许补」不算落地——`AGENTS.md` 里那条「prompt 里的硬约束要有落地」就是为这种事立的。
- **字数档是决定项，骨架可以不全用，而且得事前限量。** 最初写的是「骨架一条都不许丢」，结果与「不许加事实」「不超字数档」三条互相打架——骨架动辄三五十条塞不进 800 字，模型选了丢字数，**实测两篇超一倍（1176 / 1443 字）**。改成「骨架是素材库，装不下的可以不用」不够：只写「字数档是决定项」也压不住（目测三道题 1119 / 991 / 950，全超）。真正管住的是**事前限量**：量出一条骨架条目**平均 41 字**（池子 461 条 / 19070 字），按档反推最多喂几条（900 字档 → 21 条），**按栏轮流取**保证每栏都有人。实测（房车那篇 54 → 21 条）：材料从 1119 字落到 727 字；三道重跑全部进档（727 / 654 / 728）。少给素材没有伤到事实覆盖，回链核对仍是零加料。
- **一个代号只能代表一个地方**（实测抓的假事实）。骨架里上海浦东与重庆高新区分得清清楚楚，材料里被并成同一个「D市」干的两件事——**材料声称一个城市做了两件事，而原文是两件。虚化这一步自己制造了假事实。** 加这条后重跑，回链核对零加料。同样地，**机构名也要虚化**（写「某高校」「一行业协会」），人名保留姓或改成「某先生 / 某教授」。
- **建议要保留建议性质**。骨架里「建议 / 主张」那栏的事还没发生，材料里不许写成已经做到的事。更进一步：**出对策题时，整篇建议不应该整段抄进材料**——否则答案现成躺在材料里，拄一遍就得分。材料里可以留一两条当干扰，不能整段搬。

## 七、可核验性：凭什么说它是对的

**【自定】四个检验，从便宜到贵：**

1. **抽样回链**（每批必做）
   随机抽 N 条骨架事实，回到一手材料核对。**报结果要连「抽了几条、错几条」一起报**，只报百分比等于没说。错误率超过 10% 就整批重做。

   **判三种，只有「支撑」算过**（见 `tools/material-pool.mjs verify`）：支撑 / 说过头（原文写了但条目把话说满、或改了数字与限定语）/ 找不到。后两种都计入错误。

   **【实测】实际错误率约 8–10%，比「抽 15 条错 ≤1 条」这条线宽**（2026-10-15）。四批合起来 **87 条错 7 条 = 8.0%**：

   | 批次 | 抽 | 错 | 错了哪一类 |
   | --- | --- | --- | --- |
   | 第一批 | 15 | 1 | 主体上移一层 |
   | 第二批 | 24 | 2 | 语气拉高（印象→认为、纳闷→质疑） |
   | 第三批 | 24 | 2 | 语气拉高（同两类） |
   | 第四批 | 24 | 3 | 限定语丢掉（「前不久」/「房车热门目的地中」/「张力表示」） |

   「抽 15 条错 ≤1 条」等价于要求 ≤6.7%，**比实测水平略严**。**这条线暂时不改**，但心里要有数：卡在 1 条与 2 条之间不代表这一批变坏了。真正该看的是**错的是哪一类**。

   **【实测】四批的错全是同一家族：限定语被抹掉**——主体（「张力表示」→ 陈述句）、语气（「印象」→「认为」、「纳闷」→「质疑」、「还可参与」→「积极参与」）、时间（「前不久」、「今年以来」）、范围（「房车旅居热门目的地中」）。它不是编造，字面上看着都有依据；但出题时会变成采分点，**答对了的人反而被扣分**。三次收紧 prompt （逐条列反例、把原句钉进去）把错误率从 21% （5/24）压到 12.5%（ 3/24） 后就不再动了——**prompt 这一层的噪声底就在这里**。要再往下压得靠两个动作，都不是改 prompt：① 落盘前对高风险条目（含归属词「表示/认为/建议/称」与含数字的）先回链核一道，核不过的当场重写；② 把 `verify` 从「每批抽一次」变成「每次改过 prompt 必跑一次」。

   **为什么反复栽在这一族上**：它是**向强改**——把「印象」说成「认为」读起来更像书面语，模型发自内心觉得那是改好。同一道理反向不成立（并列的事拆开、只取一部分），那种「向弱改」是允许的（见第五节第 1 条）。审这份产物时方向感比敏感度重要。

   **【实测】错误高度集中在一个病灶：主体与范围被改写**（同日，三批抽样里的三条错全是这一类）：
   - 原文写「相关工作人员说」→ 条目写「工作室宣称」（主体上移一层）
   - 原文写「王雪的个人观点」→ 条目写「有观点认为」（个人意见被说成公论）
   - 甲地套取 9 万元 + 乙地的另一案 → 被并成「套取资金」一条（两件事并成一件）

   **为什么这一类最有害**：它不是编造，字面上看着都有依据；但出题时它会变成采分点，**答对了的人反而被扣分**。所以提炼规矩里单独立了一条（第五节规则 11），核对时也优先看这一类。

2. **双源交叉**（关键数字必做）
   材料里的数字，去**官方数据**对一次。对不上的，**要么改数、要么删掉这个事实**，不许「大致对得上」就放过。

3. **独立重做**（换模型）
   换一个模型，从同一份一手材料重新提炼一遍骨架。**两份一致的部分可信，分歧的部分标记为可疑**——这是最省力的可疑点探测器。

4. **人类试做**（重要批次做）
   出的题让人真做一遍，检查：答案唯一吗？选项有歧义吗？材料够不够回答？**这是最硬的检验，也是唯一能抓住「题目本身有问题」的手段**——前三条都只能验证事实，验证不了题。

**【自定】真题对标**：真题是唯一可对标的外部标准（官方没有命题规范可依，见第一节）。对标的是**形态**：材料长度、题量、能力分布、设问方式。**不是对标具体内容。**

## 八、时效：什么材料会过期

**【自定】默认半年。** —— 2026-10-15 定。

判据不是按材料类型分，因为它其实只需要问一句话：

> **这份材料的价值，在于「它是新的」，还是在于「它定了什么」？**

| | 例子 | 什么时候不能用 |
| --- | --- | --- |
| **在于是新的** | 某市去年推行的做法、某月的经济数据、某次活动的报道 | **发布起满半年** |
| **在于定了什么** | 五年规划、党代会报告、国家战略、法律与长期有效的政策文件 | **不过期**（它定义的是框架，不是时点）

**大事件为什么不过期**：下一次同类文件出来之前，它一直是现行框架；拿它出题，问的是「这套部署说了什么」，而不是「最近发生了什么」。**一份五年规划放到第三年，依然是有效的命题材料。**

**【自定】拿不准就按半年算。** 宁可用于旧材料少一个选题，不可拿一份过期的材料出一套看着新、其实已经变了的题。

**【自定】过期不等于删。** 骨架留着（它不占地方、也不再出题），池子淘汰的只是「能不能出题」这个资格——哪天要回头查「这条事实当时是从哪来的」，还得有东西可查。**时效按骨架头部的「发布」算，不按「抓取」。**抓取日期与发布日期差半年的材料（抓得晚）入库就已是过期货，不得入库。

**【自定】没有分类表也不靠模型判**。判「它是不是大事件」不交给抓取或提炼环节自由心证：**先看来源**——一手政策文件多半是长期框架，新闻稿多半是时效消息；再从骨架头部带的「文号」看出来（有正式文号的，按大事件处理；没有的按半年）。**判不出来的一律按半年。**

## 九、还没解决的

**如实列在这里，不许当成已解决：**

1. **没有官方命题规范可依**。第一节已说明。这意味着这套流程**天然只能自称「练习仿真」，不能自称「对标官方」**。
2. **真题溯源没有权威版本**。想检验「我们的材料像不像真题的材料」，**没有现成的对照物**，只能自己拿真题文本反查。这条路没走过。
3. **法律法规库的接口没打通**。`flk.npc.gov.cn/api/` 存在，但 HTTP 方法与参数未经本机实测，**在没验通之前不许写进代码**。
4. **统计局数据库接口 403**。发布页与公报页可抓，**逐项取数的接口走不通**——需要数字时可能得从公报正文里抽。
5. **提炼环节的误差，目前只有一次样本**。2026-10-14 拿一份近 8000 字的政策文件走了一遍全链（抓取 → 提炼 → 出题 → 拿原文核对）：骨架抽查 15 条，13 条原文能支撑，数字零处对不上；**出题那一步编了一条**——材料里写「省级民政部门掌握进度主要靠层层报表」，骨架里没有这句。10% 这个阈值仍然是估的，样本量不够。
6. **材料的时效只有一条线，没有分级**。半年 + 大事件不过期（第八节）是 2026-10-15 定的，**没经过实跑检验**——池子跑起来之后才知道半年这个数对不对（抓回来的材料里有多少是过期的、有多少大事件被误判成时效）。

## 十一、材料怎么到用户手里

池子本体在仓库的 `materials/pool/`（不是本机某个目录）：要发出去的东西跟代码走同一套流程，
改动看得见、有历史、能回滚——**审材料就是看 diff**。它不跟安装包走，单独发在一个固定 tag 的
prerelease 上，应用启动后自己拉；安装包里只带一份兜底，且**只在池子还是空的时候播**。

发布与验收的机制细节在 `docs/发布与更新.md` 的「材料发布」一节；这份文档只管材料的规矩
（什么能进库、怎么提炼、什么时候过期）。
