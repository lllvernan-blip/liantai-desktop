# 全站控件形状与高度统一

日期：2026-11-01 · 状态：已实施

## 背景

入口屏在 ADR 0001–0003 里连续三轮改成胶囊，纸面里的其余控件没跟上。用脚本把十三个屏的控件实测一遍（`getBoundingClientRect` + `getComputedStyle`），同一类控件在不同屏上落成了四套几何：

| 控件 | 实测（圆角 · 高 · 字） | 出现位置 |
| --- | --- | --- |
| `.chip`（模块/文种） | 30 / 33 / 37 三个高度都是胶囊 | 起始页 30、落地页与分组 33–37 |
| `.primary` | 36 或 40 | 在 `.actions` 里 36，独处时 40 |
| `#pdHome` | 47、字 16 | 快判小结（挂 `.big`，但没有 `.startbox` 那份 64） |
| `button.linkbtn` | 28 / 30 / 31 | 工具栏 30、步骤条 31、页脚 28 |
| `.navrow`（画像可点行） | 直角 0px | 弹层里 13 行 |
| `.etag` / `.pill` / `.typestat .t` | 8px 方底标签 | 批改页、答题页 |
| `.tour-tip button` | 8px | 引导气泡（全站唯一一处方按钮） |

圆角上同样是三套并行：胶囊（入口）、8px（纸内按钮与容器）、0px（可点行）。

## 决定

1. **按钮一律胶囊**，包括顶栏图标键、纸内动作、弹层、引导气泡与官网下载按钮。容器（输入框 / 下拉 / 选项行 / 材料 / 答卷 / 范文 / 弹层）留 `--r-ctl` 8px——「按的东西」与「装东西的盒子」本来就不是一回事，形状不同是在说明它是什么。
2. **高度四档，不按屏另起**：36 常规控件、30 胶囊与文字键、48 入口科目胶囊、64 入口主行动。多行选项按内容长高。
3. **主次靠颜色分，不靠高度分**：`.primary` 回到 `--h-ctl`，与同排按钮齐平。红已经够重，再高 4px 只是把一行拉歪。
4. **同一 `.big` 只许一种几何**：快判小结的「回首页」不再挂 `.big`（它原来既不是 64 也不是 36，卡在 47），改成普通描边按钮，让「再来一轮 / 回首页」成为同一行里的主次两颗。
5. **内边距不再兼职定高**：`--pad-ctl` / `--pad-ctl-sm` 删除，按钮与胶囊给 `0 24` / `0 16`，高度交给 `--h-ctl*`。原来 `8px` 上下内边距让 36 档实际算出 37，与同排 36 差 1px，看着像没对齐。

## 落地

- `app/index.html`：`button` 基类圆角改 `--r-pill`；`.primary` / `.ghost` / `.linkbtn` / `.chip` / `.iconbtn` / `.mhead .x` / `.fab` / `.metarow>.linkbtn` / `.tour-tip button` / `.seg` 外壳一并归位；`.navrow` 改 `--r-ctl`；`.pill` / `.etag` / `.typestat .t` 改胶囊；`#pdHome` 由 `.big` 改 `.ghost`。
- `site/index.html`：下载主按钮改胶囊 64 高、字 26（与应用里的入口主行动同一颗按钮的两种语言），右侧箭头块改成胶囊右半。
- `tests/assertions.js`：新增「控件形状」两条——按选择器扫全站 CSS，按钮类规则的圆角只许 `--r-pill`（内层分段由胶囊外壳裁剪）；`.primary` 必须走 `--h-ctl`。快判小结那条断言从「有这两个按钮」改成盯整行 markup。

## 不做什么

- 不给输入框、选项行、材料、范文加胶囊：它们是盒子，胶囊会让长文本看着像一颗巨大的按钮。
- 不为「统一」把 Windows 与 mac 的字体抹平（见「跨平台」节）。
- 不动版面尺度与间距五档：这一轮只收形状与高度。

## 追加（同日）：字撑壳，不让壳撑字

形状统一之后仍有一处不对劲：14px 的字装在 36px 的胶囊里，字只占壳高的一半；主按钮 26px 装在 64px 里，左右还各留 58px，两个字的标签撑出一枚空壳。判断是「壳大」还是「字小」，落到数上其实是一件事——字的占比。

改法取「字往上走」而不是「壳往回收」：

- 五档字号整体上移一档：`13 / 15 / 17 / 28 / 32`（原 `12.5 / 14 / 16 / 26 / 30`）。13px 仍在 Microsoft 规范的最小 12px 之上，15px 高于它给的正文 14px。
- 横向内边距收窄：按钮 `24 → 16`、主按钮 `58 → 40`。内边距只许落在间距五档里（16 是档内值，20 不是）。
- 高度不动。收高度会让「一屏只有一个重量级」的层级一起塌掉；字变大以后同样的壳读起来就轻了。

纸上的字（材料 / 作答 / 范文的 16px）不动：它们不是控件，行宽与行长已经按 17–40 字算过。
