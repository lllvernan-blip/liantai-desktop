# 入口主行动跟状态、卷首两档、交卷吸底

日期：2026-11-01 · 状态：已实施

## 背景

一天之内入口屏改了四轮（ADR 0001–0004），每轮都在调几何；但真正卡住考生的不是入口好不好看，是三处**层级给错了地方**：

1. **回来续练的人被截胡。** 有没做完的题时，最重的东西仍是「开始快速判断」（64 高红胶囊），「继续上次」是 36 高的描边键、排在两颗科目胶囊下面，是全屏第四重。回访的人最常见的意图是接着写。
2. **卷首每屏吃掉约 185px。** 顶栏 46 + 机关名 30px + 红线 + 文号行，内容要到 y≈200 才开始。作答页、批改页、快判页都照搬整套卷首；900×600 下作答框只露一条边，「提交阅卷」不在首屏。
3. **交卷会滚出视口。** 1280×800 下「提交阅卷」底边 739，刚好压线；答案一长、窗口一矮就要滚。作答过程中没有固定的出口。

三处的共同点：都按「屏」排层级，没按「此刻在干什么」排。

## 决定

1. **首页主行动跟状态走**：有 24h 内未完成练习时，红按钮是「继续上次」，副标报「科目 · 模块 · 子类型 · 停在哪」；快判退成 chiprow 第一颗胶囊。没有恢复现场时，红按钮仍是快判（10-07 定的「快判是第一入口」保留）。**缺 Key / 缺模型时不出这个切换**：题能打开、能写，但交卷那一步还得回头填，先答应再反悔；这时主行动仍是「先填 API Key / 先选模型」，恢复退回那行描边键。
2. **卷首分两档**：入口 / 快判小结 / 批改用完整版；作答类工作屏用页眉版（同一套 DOM 换排法，机关名 17px 与「模块 · 题型」并成一行，文号仍在右、红线仍在下）。判定收在 `compactHead()`。
3. **交卷吸底**：提交那一行改 `position:sticky;bottom:0` 的动作条（`.actbar`），纸色底 + 上缘细线。

## 落地

- `app/index.html`：`startBoxHtml` 首页分支重写（`resumebig` / `qkChip` / `setupLine`）；新增 `resumeText()`（首页副标与科目页那行共用一句话）；新增 `compactHead()` 并在 `renderHeader()` 里 `classList.toggle("compact")`（桩里 classList 是空壳，先判方法在不在）；`.doc.compact` 一组样式；`.actbar` 样式；`draftPanelHtml` 的动作行加 `actbar`（这个函数后来拆成了 `draftCtrlHtml` / `draftAnswerHtml`，见「两栏同线」那次改动——按本 ADR 去源码里找 `draftPanelHtml` 会扑空）。
- `tests/assertions.js`：新增三组——首页两种状态的主行动层级、`compactHead()` 五屏判定、交卷行是 sticky。
- `docs/界面规范.md`：新增「卷首（两档）」「作答出口（吸底）」两节 + 首页主行动那条。
- `AGENTS.md`：「起始页骨架」那条补首页跟状态走。

## 实测

- `.redhead` 高度：完整版 85 → 页眉版 36；1280×800 作答页内容起点 200 → 123。
- 900×600 作答页：交卷底边 588（视口 600），改前在首屏之外。
- sticky 在 `overflow:clip` 的纸面里生效（滚动 200 时动作条底边钉在 600；滚到底后回到自然位置，无遮挡残留）。

## 不做什么

- 不做竖向居中把按钮往下拽：窗口变高时按钮不该漂（ADR 0002 的结论保留，只是理由从「眼感」换成「锚点固定」）。
- 不把页眉版做成「删掉机关名」：公文感立在红线上，删字省下的 30px 换不回那点身份。
- 不用 fixed 吸底：纸面是 `overflow:clip`，fixed 会飘到纸外。
- 不动留白五档、纸宽曲线与两栏门槛：这一轮只改层级与出口位置。

## 后续

决定 1 的「副标报哪一科 · 停在哪」当天就撤了，恢复入口两处都只剩按钮自己：

- 首页红按钮退回一颗只说「继续上次」的 `.primary.big`。两档字号装在 64 高的胶囊里排不齐——`display:inline-flex;align-items:baseline` 会把整组字钉在胶囊上沿（实测字墨顶边与按钮顶边同为 40，下面空出 25px 红），而按钮自己的 UA 布局本来就把字居中。
- 科目页那颗描边键左边的信息句一并删（`.al-main` 下线，键改为在动作列里居中）。位置与轻重已经说了「这是一件比出题轻的事」，去哪一屏由点进去的那一屏报——不必要的次要标签和描述不留，让布局本身传达信息。
- `resumeText()` 随之删除；`resumebig` / `.rb-sub` 不留死样式。
