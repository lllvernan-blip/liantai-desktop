# 按钮三档、换一题二次确认、批改页主行动与控件字族

日期：2026-11-01 · 状态：已实施

## 背景

P0 把三处层级摆正之后（ADR 0005），同屏还剩下三类「层级没落地」的问题，外加一条被反复说「像 Demo」的排印问题：

1. **同一行几颗按钮一样重**。作答页那一行「换一题 / 翻学习卡 · 已翻 0 次 / 先归类再写 / 不限时」四种控件并列，全是 30 高的描边胶囊；而其中「换一题」是会丢掉这一稿的动作，跟工具同权重、也没有拦一道。更糟的是同一颗键跨屏三种长相：`.qtop`、`.ghead`、`.metarow` 各写了一条给 `linkbtn` 补 1px 边的规则。
2. **「换一题」一点就换**，作答框里写了 300 字也照换——草稿虽然还在，但人不知道，会以为白写了。
3. **批改页的主行动是「完成」**（红按钮），点了回首页；真正的下一步「同模块再来一道」是次级。页头还挂着一颗「换一题」，跟底部那颗说的是同一件事。
4. **排印**：控件栈当时以 `-apple-system` 打头（mac 上不报错，但拉丁与数字交给 SF、汉字交给苹方，一行两种骨架），而品牌与区块标题走 `"SimHei","黑体"` 那条栈——这两族在 mac 上不存在，整条落到 `sans-serif`，等于「没指定字体」，于是同一屏上按钮与标题是两张脸；再叠上 `letter-spacing:2px`（入口主行动）、`1px`（区块标题）、`.5px`（灰字标签）的汉字拉距，以及主按钮悬停的 `translateY(-1px)` + 投影，整屏读起来像网页模板。实测证据见下。

## 决定

1. **按钮只三档**：主 `.primary`（红，一屏一颗）/ 次 `.ghost`、无类名（描边，给离开与退一步）/ 工具 `.tool`（无框无底、正文色字、悬停一层 `--wash`，30 高）。文字键不再按屏补边；危险确认用 `.tool.danger`，不给实心红。
2. **主按钮悬停只换色**：撤掉 `translateY` 与 `box-shadow`，`--sh-1` 一并删除（阴影只剩下拉浮标与弹层）。
3. **换一题会丢稿就拦一道**：作答框里有字时，键自己变成「清掉这次作答，换一题？」，再点一次才真换，4 秒不动自动收回；框里空着直接换。不开弹窗——写题中途被遮罩罩住比误点更烦。
4. **批改页主行动改成「同模块再来一道」**：完成退成描边、看我的画像退成文字键；普通题页头不再放「换一题」，整卷只放「回整卷」。
5. **控件字族与字距**：`--yahei` 按本机真命中排（苹方 → 冬青 → 雅黑 → 思源黑），`--hei` 并成 `var(--yahei)`；按钮、科目栏、品牌、区块标题、灰字标签一律 `letter-spacing:0`，全站非零字距只剩红头两处（4px / 2px）；按钮字不小于 15px。

## 落地

- `app/index.html`：`--yahei` 换栈；`button` 基类 `letter-spacing:0`；`.primary` 字距归零、内边距 24、悬停只换色；新增 `.tool` / `.tool.danger` / `.switchconfirm` 一组；删掉三处「给文字键补边」的特例；`wireSwitchBtn()` 统一接管两处接线；`gradeHtml` 的 `.nextrow` 换主次、页头 `#btnSwitch` 只留整卷；`.fab` 从描边胶囊降成文字键；`.selfrow button` 13px → 15px；撤 `--sh-1`、`--line-hover`。
- `tests/assertions.js`：新增「按钮三档」「批改页主次」「换一题空框直接换」三组；「批改页照样有换一题」等四条旧断言按新规则改写；三处 `#btnSwitch` 连点两次（先拦后换）的用例同步。
- `docs/界面规范.md`：新增「按钮主次（三档）」「控件字体」两节。

## 实测

- 作答页工具行：`翻学习卡` 由描边胶囊 → 文字键，与 `归类`、`换一题` 同一档；`限时` 仍是有边的输入框（它是「要填的框」，不是「按的东西」）。
- 批改页底部：`primary|同模块再来一道 · ghost|完成 · tool|看我的画像`；普通题页头 `#btnSwitch` 已不存在（整卷仍有「回整卷」）。
- 字族实测（1280×800，Chrome `CSS.getPlatformFontsForNode`）：`.startbox button.primary`、`.toolbar .brand`、`.toolbar .subjbtn` 全部只报 `PingFang SC`；改前 `-apple-system` 打头时同一串字会报 `.SF NS×11 + PingFang SC×8`。入口主按钮宽度 262 → 250（少了 2px×6 的字距）。
- 顺带修掉一处被放大截图抓到的裁切：限时框占位字「不限时」45px + 内边距 16 = 61，框宽 62，右对齐下第一个字被切一条边；框宽改 72，三位数分钟也放得下。
- 换一题：框里有字 → 第一下只改键、`pendingGen` 仍为空；再点一次才进等待页。
- 自检 233 / 1206 / 20 全绿，闸门 9 项全过。

## 不做什么

- 不给文字键加图标：图标要一套自绘 SVG，属于下一轮（`.tool` 的最终形态是「图标 + 字」，现在先统一到字）。
- 不动胶囊这个形状：ADR 0004 这一轮不推翻；入口主行动 28px + 全胶囊仍偏「招牌」，要不要收圆角另开一题。
- 不动顶栏四颗图标：导出 / 导入搬进设置、记录提到顶栏是下一步的事。
