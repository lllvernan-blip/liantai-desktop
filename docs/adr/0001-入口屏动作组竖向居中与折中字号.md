# 入口屏动作组竖向居中，次级入口上移，字号块高取折中档

入口屏（首页 / 科目页 / 模块页 / 快判页）的动作组不再顶齐红头、下半纸留白，
改为在红头下方的剩余纸面里垂直居中（纸随内容长高，不存在裁切）；
次级入口（科目两块 / 模块 chips）排在主按钮上方，红色主按钮压住纸面中线。
字号块高从「一屏三块」的放大档（主按钮 620×96 / 字 30，科目块 304×96 / 字 26）
降为折中档：主按钮 620×64 / 字 26，科目块 304×48 / 字 16，恢复键 36 高，进度行 14px，
间距一律 24 档。

2026-11-01 早上曾把入口放大并顶齐红头，理由是「小按钮在宽纸上像便签」；
实际使用中用户（唯一参照用户）判定「又大又笨重」且「纸面太空」——大块解决了
便签感，却把空白全压到下半张纸，纸面失衡。竖向居中让空白上下均分，纸面立得住；
次级入口上移形成「先看到能练什么、主按钮开始」的顺序；折中字号让主行动仍占得住
纸面、科目块回到正常控件尺度。替代方案（回退成小胶囊、添新内容填空白）分别输在
便签感复现与违反「入口不添新」约束。

后果：`docs/界面规范.md` 入口规格两条按本决策改写；矮窗（900×600）下居中与滚动
行为已实测无溢出、无裁切。
