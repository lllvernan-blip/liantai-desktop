# 界面质感：只借 Material 的工程性规范，排印参照 Kami

日期：2026-11-01 · 状态：动效已定档、行距已比过并维持原值；状态层与题面括号待决

## 背景

提法是两个：「按 Material 规范优化整体 UIUX」+「参考 Kami」。

Material 的招牌动作与本项目已定的视觉路线正面对冲——那条路线是**保留公文卷面与红头这张辨识度名片，只借「工具感的克制」**（对齐、字号节奏、控件一致、少边框），并且写死了停手线：hero 化、卡片化这类动作一旦碰红头或纸感就停手。卡片、elevation 阴影、8dp 网格、Roboto 字阶、涟漪、M3 配色，六条全在那条线上。

真实痛点不是「不够 Material」，是使用率低的自陈原因里有一条「界面不够好看，没动力打开」——那是长期指标第二项（第二天还想打开），值得做。所以问题从「换不换风格」变成「借哪几条」。

Kami 查清是 [tw93/Kami](https://github.com/tw93/Kami)：HTML/CSS → WeasyPrint 的印刷级排版约束系统。它的参数里有一部分能搬到屏幕，有一部分是印刷专属。

## 决定

1. **不整体换 Material 长相**，只借它不碰视觉身份的那几条工程性规范：热区下限、焦点指示、对比度、状态层、动效时长与缓动、表单字段结构。
2. **排印纪律参照 Kami**，但只搬屏幕适用的：行距分档、标题邻近律、字号禁中间值。mm/pt 边距、分页契约、印刷专属字距不搬。
3. **动效先定档**：时长三档、曲线两条，数字与曲线取 Material 3 motion tokens，全档 ≤240ms 不破动效预算。
4. **行距比过三档，维持 2.05**。1.9 与 1.8 各多装得下 1 行与 2 行（材料窗净高 416px 下 12 → 13 → 14 行），换来的密度不值这一眼：屏读这一族宁可松。2.05 超 clreq 上限这件事照旧成立，只是它现在是**比过之后留下的**，不是没看过。正文那一族其余几个值（1.6 / 1.7 / 1.75 / 1.85 / 1.9）用在说明字与解析上，不在这一族里，收不收另说。

## 体检读数（决定依据，不是猜的）

- **行距从没定过档**：全页 37 处 `line-height`、11 个取值。字号定过五档、间距定过五档、控件高定过四档，只有这一族没有。管正文的有 8 个值（1.35 / 1.6 / 1.7 / 1.75 / 1.8 / 1.85 / 1.9 / 2.05），其中 2.05 用在材料、作答、范文、判后回看四处，规范自陈「略超 clreq 的 1.5–2.0 上限，是自定、没动」。
- **动效六个野时长**：`.12 / .15 / .16 / .18 / .2 / .22s` 散在七处，且按钮基类与后面的状态规则各写了一遍同一件事，后者覆盖前者——前者是死声明。缓动只有浏览器默认的 `ease` 与一条自定曲线。
- **已经达标的三条不拿来凑数**：焦点环对比 5.4:1（门槛 3:1）、弹层有 Tab 焦点陷阱、灰阶三档是对纸面算过 WCAG 比值的、画像行用 `<button>` 所以键盘可达。
- **disabled 用一层 opacity 糊平**（`.5`），把字和边一起变淡，读成「这块没了」而不是「这颗不能按」，且与自家「灰阶下限 4.5:1」打架。Material 的做法是内容与容器分开定值。

## 不做什么（以及撞了哪条）

- **卡片 / elevation 阴影 / 大圆角**：撞「纸就是纸」与红头停手线。
- **8dp 网格**：现有五档间距与 8dp 制本就兼容，换了等于没换。
- **Material 字阶（Major Second）**：五档字号有 WCAG 与 Windows 规范下界作依据，28 / 32 两档另有用处。
- **state layer 的 rgba 叠加**：破「设计色只走 token」，且 hover / active 已有等价的换色做法。
- **热区抬到 48 / 44**：桌面指针下 WCAG 2.5.8 的底线是 24px，最小档 30px 已过；「模块 chips 小一号」是刻意的次级。
- **涟漪、FAB、M3 配色**：全站只有一块红是身份。
- **中西文之间加空格**（Kami 有这条）：看着「缺空格」的 `不超过350字`、`综应A`、`给定资料1` 全是照真题原样抄的题面与科目名，加了反而失真，且被「题型表以官方大纲为准」压住。

## 落地

- `app/index.html`：`:root` 加三档时长与两条曲线；七处字面时长与 `ease` 全部改走 token；删掉按钮基类那条被覆盖的死 `transition`；`[data-tip]` 的出场延迟并入入场档。
- `tests/assertions.js`：两条新断言——声明里不许出现字面秒数、不许出现 `ease` / `ease-out` / `linear` 这类默认曲线，且五个 token 必须在。
- `docs/界面规范.md`：「二 硬线」加一条（只写判断，像素与 token 名留在代码与断言里）。
- `文档/参照-好设计们/行距三档对照.html`：2.05 / 1.9 / 1.8 三档，用材料池里未改写的真材料，自己量行高、窗内可见行与差几行。

## 实测

- token 在浏览器里全部解析成功：按钮 `transition-duration` 为 `0.15s ×4 + 0.1s`，曲线 `cubic-bezier(0.2, 0, 0, 1)`；入场 `riseIn 0.2s cubic-bezier(0.05, 0.7, 0.1, 1)`。
- 样张读数（材料窗净高 416px）：2.05 可见 12 行 / 1.9 可见 13 行 / 1.8 可见 14 行，这段材料共 17 行。作答框净高 266px：8 / 8 / 9 行。
- **行距不改行长**，所以 760 与 1304 两个纸宽数（由 38 字/行反推）不受这件事影响，不用重算。
