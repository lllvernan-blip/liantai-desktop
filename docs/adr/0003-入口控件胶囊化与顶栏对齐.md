# 入口控件胶囊化：宽度跟字，模块 chips 实体化，顶栏品牌位居中

入口屏（首页 / 科目页 / 模块落地页）的按钮从 8px 小圆角矩形改为全站胶囊
`--r-pill`，宽度由文字加内边距决定，不再拉满 620 动作列；「做一套题」的
通栏横条同样改为跟字居中。科目页原先的透明灰字模块 chips 换成看得见的
实体胶囊（`--ctl` 底 + `--chip-line` 描边，比主按钮与科目入口小一号），
选中态回落到全站 `chip.on`（红线 + 淡红底，与科目栏同一套语言）。
顶栏品牌位改 `inline-flex` 垂直居中，去掉图标 `vertical-align:-4px` 的
基线微调——图标与「练习台」三字共一条中线，与旁边的科目胶囊、右侧图标对齐。

理由：用户（唯一参照用户）判定 8px 圆角「太方正」，胶囊是惯例做法；
按钮宽度跟字走才有「按字来的热区」，拉满列的胶囊读不出边界，也没必要
（Apple HIG 只在移动端推荐通栏按钮，桌面入口不适用）；透明灰字模块入口
与「键必须是看得见的按钮」这条既有判据冲突，实际截图里两轮都被读成
说明文字。顶栏对齐依据 flex 居中惯例（MDN flexbox 对齐），基线微调
是给行内布局打的补丁，改 flex 后不再需要。

后果：`docs/界面规范.md` 入口规格与「版面共同基线」两条按本决策改写；
`AGENTS.md` 里「模块切换 chips 透明底」一句改为「必须是看得见的胶囊」；
`tests/assertions.js` 入口屏断言改为盯「胶囊 + 不拉满列」。
