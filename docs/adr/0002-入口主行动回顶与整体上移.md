# 入口主行动回顶，次级入口跟下，动作组整体上移

入口屏（首页 / 科目页 / 模块页 / 快判页）取消「次级入口在上、主行动居中」的排法
（ADR 0001）：红色主按钮回到红头下第一行，科目入口 / 模块 chips 跟在其下，
恢复入口与进度行不变。动作组仍在剩余纸面里竖向居中，但底部垫高 100px——
整簇重心比几何中心高约 34px，空白变成上小下大。

ADR 0001 把次级入口挪到主按钮上方，理由是「先看到能练什么、主按钮开始」；
实际使用中用户（唯一参照用户）判定：主按钮是这一屏要办的事，压在次级入口
下面显得主次颠倒；且竖向居中后整簇重心偏低，纸面仍然偏空。主行动回顶恢复
「红头 → 这屏要办的事 → 其他去处」的阅读顺序；整簇上移回应「布局往上移一点」。

后果：`docs/界面规范.md` 入口规格一条按本决策改写；ADR 0001 的「次级在上」
部分被本决策替代，折中字号与竖向居中保留。矮窗（900×600）下垫高后纸随内容
长高，无溢出无裁切（真浏览器实测）。
