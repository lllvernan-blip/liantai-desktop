# 验证工具（探针 · 漂移 · 取景器）

`AGENTS.md` 的「修改后验证」节只留入口与判据；**细节都在这一份**。做这几件事之前先读它，别凭记忆改工具参数。

## 自检

`node tests/run.mjs`（项目根目录）必须看到 `N/N passed` 且退出码 0。零依赖：它把 `app/index.html` 的唯一 `<script>` 抠出来、配最小 DOM 桩子、在 Node 里跑 `tests/assertions.js`。

两个平台的通过数不一样（不是出错）：壳侧 `tests/shell.mjs` 的第 6 组只用 macOS 的解压与 plist 工具（`ditto` / `PlistBuddy`），别的平台会打印一行「跳过第 6 组」；页面那份两边一样。**别把数字抄进文档**——每加一条断言它就会变。

改动涉及窗口 / 启动 / 加载方式：真跑一次 `npm start`，确认 `logs/startup.log` 里有 `did-finish-load`、没有 `did-fail-load`。涉及浏览器交互、异步请求、设置弹层、导入导出或本地存储：用真实路径走一遍并检查控制台错误。

## 探针（量一段真行为）

```bash
node tools/probe.mjs 我的探针.js
```

它把 `app/index.html` 的脚本抠出来、配最小 DOM 桩子跑，探针里可以直接用应用的全部函数与常量（`MODULES` / `moduleAvg` / `gen` / `pickSubtypeFor` …），也支持顶层 await。探针是一次性的，用完删掉，别往 `tests/` 里塞。

**别用 `node -e` 写带 JSON 片段的探针**：参数里只要同时出现「冒号」与「反斜杠」，Git Bash 就会把这段当路径列表改写（`\"` 变成 `/"`、`\\` 变成 `//`）。轻则语法错误，重则搜索串被悄悄改掉、程序照跑并返回 `false`，看起来像「功能没生效」，能白排查半天。`MSYS_NO_PATHCONV=1` 与 `MSYS2_ARG_CONV_EXCL='*'` 都治不住，老老实实写成文件。

## 阅卷漂移（同一份卷子反复批会不会给不同分）

```bash
$env:LIANTAI_KEY="sk-…"; node tools/drift.mjs prepare    # 真接口出一道题，落成 %TEMP%\liantai-drift-case.json
# 打开那个 JSON，把 answers.clear（写明具体事实）与 answers.edge（八条全点名、零细节）都写好
$env:LIANTAI_KEY="sk-…"; node tools/drift.mjs run 5      # 每份答卷批 5 次，打印各次得分、极差、哪几个子项在摆
```

它走的是 app 里真实的 `gen()` / `grade()`，不是另写一份 prompt。**基线必须两份答卷都跑**：2026-09-29 第一次只测了「写具体」那种，5 次一字不差、极差 0，看着像根本没病；换成「只点名不给事实」的答卷才暴露出来（极差 4.5/20）。Key 只从环境变量读，不进仓库。

## 取景器（量真实布局）

```bash
caffeinate -d -u -t 900 node tools/shot.mjs tools/scenes-ui.mjs _shots/ui
```

起临时静态服务 + Electron 真渲染，**每个场景拍两张**：原始态 + 折叠块全展开态（`--plain` 只拍原始态）。折叠起来的内容不展开就等于没进保护范围，所以不为它另写一套场景。

- **跑之前先把显示器叫醒**（`caffeinate -d -u`）：显示器休眠时 macOS 会掐屏幕合成与隐藏窗口的重绘，同一套场景能慢十几倍——实测 3 屏 6 张图从 45 秒变成 17 分钟，CPU 还几乎不动（看着像「卡死」，其实是等系统）。
- **量「可见字」必须显式排除 `details:not([open])` 的子元素**（`shot-app.cjs` 里的 `inClosed()`）：关着的 `<details class="expline">` 自己高 40px，而它里面 `.expbody` 的 `offsetHeight` 照样报 38~96px。不排除的话，原始态那一遍一直在连收起的内容一起数，展开态那一遍也就白跑了（2026-09-29 修正）。
- **三条纪律**：① **同一份代码连跑两遍要逐张字节一致**——`PRELUDE` 把页面时钟钉在固定时刻并关掉全部动画过渡，改场景时别把这两处弄丢；比对用 `node tools/cmp-shots.mjs <旧目录> <新目录>`，**先自证稳定再去比改动**。② **展开态不能留给下一屏**——页面在场景之间不重载，「全展开」那一遍打开的 `details` 会污染下一屏的「原始态」；展开时打 `data-shot-expanded` 标记、截完图立即恢复；判「原始态可信」的土办法是 base 与 `__展开` 两张图的 sha256 **不应该相同**。③ `full` 场景逼重绘要按**文档全高**取尺寸（`keepH`），按默认 900 去抖会把窗口缩回去、只拍到上半截。

### 取景器自带的客观规则（`AUDIT_JS`）

每屏跑完自动过一遍：横向溢出 / 字形出纸 / 字号出档 / 可点热区不足 24px / 折叠件缺三角 / 顶栏空行 / 入口屏辅助字预算 / 页面报错；收尾把结论打在终端上，**退出码 2 = 有 FAIL**，全过就是一句「不用点开图」。

- **规则宁少勿滥**：只放用不着审美判断的客观项，误报一次以后就没人信它的结论了。
- 自检的范围是「`#docBody` + 开着的弹层面板」；纸面那两条（字形越出纸面、入口字预算）只看 `#docBody`。
- **两条 DOM 结构规则只有真浏览器查得到**：`科目入口不在顶栏第一行`（WARN，`#subjbar` 必须在 `.toolbar` 里）与 `顶栏空行`（FAIL，页签行占着高度却一个页签都没有）。node 桩子的 `querySelectorAll` 恒返回 `[]`，查不出来——这两条在 `shot-app.cjs`，不在 `tests/`。

### 入口屏辅助字预算（`ENTRY_AUX_BUDGET`）

按场景名前两位定线（首页 `01` 55 字、`02` 75、模块落地页 `03` 45、快判落地页 `12` 170、公文落地页 `26` 90；单位是「≤ 14px 的可见说明字」，空白不计），超了报 WARN 并把最大的几块打出来。

- `AUDIT_JS` 是个函数，场景名要传进去（`AUDIT_JS(name)`）。
- 数字是清理后的实测值加余量；**实质加了内容才调线，调的时候要说得出口理由；删了字就把线降回去**——否则「不添字」的压力会慢慢泄掉。
- **里面那个去空白记得写两个反斜杠**（`/\\s+/g`）：整段是模板字符串里的源码，`\s` 的反斜杠会被吃掉、运行时变成「把字母 s 全删掉」——删的不是空白。这个坑静默跑过大半年，量数偏大（同一个元素自测 20、外部探针 14，差的正好是 6 个空格）。对账办法：拿一个只量 `#docBody` 的探针跑同一屏，两边数字应当逐字相同。
